# 生活有谱家庭空间与协作规范

> 项目代号：`life-book` · 版本：v1.0 · 更新日期：2026-07-26 · 状态：P2 家庭首期实施基线
>
> 权威范围：家庭空间、成员、邀请、基础角色、记录主动共享、共同处理、提醒订阅、审计、成员退出与家庭解散
>
> 不负责：通用同步协议、账号认证、逐记录细粒度权限、物理数据库/API 字段、端到端加密方案和商业套餐
>
> 依赖文档：[产品需求基线](product-features.md)、[产品决策记录](product-decisions.md)、[领域模型](domain-model.md)、[账号与同步](account-and-sync.md)、[业务规则](business-rules.md)、[提醒规范](reminders-and-notifications.md)、[数据生命周期](data-lifecycle.md)、[路线图](roadmap.md)

本规范落实 PR-540～PR-545。PR-546 的逐记录权限不是家庭首期门槛；在它形成独立产品决策和迁移方案前，不能把 `sensitive` 或创建者身份误当成成员访问控制。

## 1. 家庭不变量

### FAMILY-001：家庭建立在账号和同步上

- 创建或加入家庭必须有 active Account、Device 和同步服务；
- 家庭记录的跨成员权威状态在服务端，设备仍保留可离线使用的授权副本；
- 通用 push、pull、冲突、墓碑、附件和设备撤销完全使用 SYNC-*，不另建一套“家庭同步”；
- 家庭服务不可用不影响个人空间本地手动功能；
- 被移除或家庭删除后，旧离线写入按 DOM-089/DOM-090 拒绝。

### FAMILY-002：个人空间始终私密

- 创建、加入、退出或被移除家庭都不扫描、推荐、复制或移动个人记录；
- 当前个人记录只有用户明确发起 SpaceTransferOperation 并确认共享后才进入家庭；
- 家庭记录不会在成员退出时自动复制到个人空间；
- 一个记录任一时刻只属于一个空间，不能同时共享到多个家庭；
- 需要在多处独立维护时使用“复制”，生成新 ID 和独立生命周期，不伪装成同一记录同步。

### FAMILY-003：首期是空间级可见

- active owner 和 member 都能查看家庭空间中的全部记录、清单项目、库存历史和适用附件；
- `sensitive` 只加强通知、预览、应用锁和 AI 使用，不把记录隐藏给某些家庭成员；
- 创建者不是记录所有者，不能阻止其他 active member 按权限矩阵编辑或处理；
- 服务端 membership 是授权权威，客户端筛选不是安全边界；
- 逐记录查看/编辑 ACL、访客和儿童角色均属于 PR-546 后续扩展。

### FAMILY-004：唯一 owner

每个 active 或 deletion_scheduled 家庭恰好一个 active owner membership。owner 不能直接退出或被移除；必须先完成所有权转移，或按家庭删除流程解散。任何失败或超时都保持原 owner。

### FAMILY-005：可扩展数量边界

家庭首期默认限制：

- 一个 Account 最多 active 加入/创建 10 个家庭空间；
- 一个家庭最多 20 个 active 成员；
- 一个家庭同时最多 20 个 active 邀请；
- 家庭名称去除首尾空白后 1–80 个码点；
- 成员显示名 1–80 个码点；空时显示经保护的账号标识；
- 单个记录、附件和业务容量沿用 QR-*，不因家庭翻倍。

服务配置可以在客户端声明的上限内降低试运行额度，但必须在创建/邀请前展示，不在提交后才丢数据。提高上限不得改变数据结构；收费分层需另行产品决策。

## 2. 家庭空间和成员状态

### FAMILY-010：创建家庭

创建流程：

1. 近期重新认证；
2. 输入名称并说明“只有主动放入这里的内容才共享”；
3. 服务端事务创建 Space(kind=family)、唯一 owner membership、空间版本和 server_verified AuditEvent；
4. 客户端建立独立 SyncCursor 并显示空家庭；
5. 不复制个人分类、标签、模板、提醒或记录。

请求以 clientMutationId 幂等；响应丢失后重试返回同一空间，不能创建两个同名家庭。

### FAMILY-011：Membership 状态

```text
active → leaving/removing → removed
          └→ active（操作取消或服务端失败）
```

- Invitation accepted 与 active membership 在一个服务端事务产生；
- Invitation 本身不创建 membership 或授予内容访问；
- 只有 active membership 可读取/写入；
- leaving 由普通 member 发起，removing 由 owner 发起；
- 状态转换期间服务端串行权限与 mutation；
- removed 是历史状态，不恢复；再次加入使用新 Invitation 激活同一组合的新 membership revision，并保留审计链。

### FAMILY-012：空间状态

```text
active
→ deletion_scheduled
   ├→ active（owner 取消）
   └→ deleting → deleted
```

deletion_scheduled 期间家庭内容只读，禁止邀请、移动、普通编辑和新提醒投递；允许 owner 取消、成员导出允许范围、查看审计和处理所有权阻塞。deleting/deleted 不允许恢复普通写入。

## 3. 基础角色权限

### FAMILY-020：权限矩阵

| 操作 | owner | member |
| --- | :---: | :---: |
| 查看、搜索家庭记录和附件 | 是 | 是 |
| 新建、编辑、复制、归档记录 | 是 | 是 |
| 完成/跳过周期、勾选清单、添加库存流水 | 是 | 是 |
| 单条移入回收站、恢复 | 是 | 是 |
| 永久删除单条记录 | 是 | 否 |
| 批量删除、清空回收站 | 是 | 否 |
| 创建/编辑分类、标签、模板 | 是 | 是 |
| 删除分类、标签、模板 | 是 | 是；必须遵循不删除记录规则 |
| 从自己的个人空间移入记录 | 是 | 是 |
| 把家庭记录移动到个人空间 | 是 | 否 |
| 把家庭记录复制到自己的个人空间 | 是 | 是 |
| 查看家庭操作记录 | 是 | 是 |
| 完整家庭导出 | 是 | 否 |
| 管理自己的提醒订阅 | 是 | 是 |
| 管理其他成员订阅/分工 | 否，首期不提供 | 否 |
| 邀请、撤销邀请、移除成员 | 是 | 否 |
| 重命名家庭 | 是 | 否 |
| 转移所有权、计划/取消删除家庭 | 是 | 否 |
| 主动离开家庭 | 需先转移所有权 | 是 |

普通 member 的“常规删除”止于回收站和恢复；永久删除及批量破坏必须由 owner 完成，统一 PD-003、PR-542 和 DATA-*。

### FAMILY-021：收紧和放宽保护

- 任一 active 成员可以把家庭记录改为 sensitive 或把 aiAccess 改为 denied；
- 只有 owner 经近期重新认证和明确风险确认，才能把 sensitive 改回 normal 或把 aiAccess 从 denied 改为 allowed；
- 放宽动作产生单独 server_verified 审计；
- 即使 sensitive，所有 active 成员仍可在解锁后查看；页面必须明确“敏感不等于只对自己可见”；
- 未来逐记录 ACL 不复用这两个字段。

### FAMILY-022：服务端授权时点

权限使用服务端接受 mutation 的顺序：

- 成员移除先提交，则其之后到达的写入 rejected_forbidden；
- 写入先被服务端接受，则事实保留并在随后移除审计中可见；
- owner 高风险命令、所有权转移、移除和家庭删除在空间级串行；
- 客户端收到拒绝后停止重放，不把内容复制到个人空间或建立“本地胜出”冲突。

## 4. 邀请

### FAMILY-030：创建和传递

- owner 创建的邀请首期目标角色固定 member；owner 身份只能通过 OwnershipTransfer 获得；
- 默认从服务端创建时起 7 × 24 小时有效，界面显示绝对失效时间和时区；
- token 至少 128 位随机熵，链接只含 token 和版本，不含家庭名、成员或记录内容；
- 服务端只保存 tokenHash，明文只在创建响应和用户主动系统分享时出现；
- owner 可以在接受前撤销；重新分享仍是同一邀请和同一失效时间；
- 可选绑定目标账号/已验证邮箱；绑定后其他账号即使持有 token 也不能接受。

系统分享表预览使用“加入生活有谱中的一个家庭空间”，不展开家庭名称或内容；用户在目标 App 登录后才查看详情。

### FAMILY-031：接受前确认

接受页显示：家庭名称、owner 显示名、member 权限、当前成员数量、全部成员可见边界、敏感不是私有 ACL、邀请准确失效时间。接受不会移动个人记录，也不会自动订阅全部提醒。

需要登录/注册时，验证完成后继续同一 invitation generation；切换账号重新检查目标绑定和容量。取消不创建 membership。

### FAMILY-032：状态与幂等

```text
draft → active → accepted
               ├→ revoked
               └→ expired
```

- accepted、revoked、expired 是终态；
- 同一账号重复接受已成功邀请返回同一 membership；
- 其他账号接受已使用邀请只得到 invite_unavailable，不泄露接受者；
- 接受与撤销按同一服务端事务顺序，先成功者决定结果；
- 容量在接受事务内再校验，满员时邀请保持 active 或由 owner 处理，不能创建超限成员；
- token 错误、扫描和限流只进入安全日志，不进入家庭审计正文。

## 5. 成员退出与移除

### FAMILY-040：普通成员主动退出

1. 显示家庭内容将从本机移除、个人内容不受影响、历史操作仍署名；
2. 提醒有未同步家庭 mutation 时先同步、导出允许内容或明确放弃；
3. 近期重新认证并确认；
4. 服务端把 membership 置 leaving，撤销订阅、会话授权和推送目标，写审计后置 removed；
5. 设备拉到变更后取消家庭通知、删除本地家庭密文/索引/附件缓存和 cursor；
6. 不自动复制任何家庭记录。

已经由 member 显式复制到个人空间且拥有新 ID 的记录不受退出影响。

### FAMILY-041：owner 移除成员

- owner 不能移除自己或当前 owner；
- 确认页显示成员、待接受转移/任务订阅和该成员尚未同步设备状态，不展示其个人空间；
- 服务端以 removing 状态阻止新写入，撤销 membership/订阅并写审计；
- 被移除成员下次联网时执行与退出相同的本地缓存清理；
- 移除不删除该成员创建的共享记录、库存流水或完成历史；
- 可以再次邀请，但旧 token、membership、订阅和权限不恢复。

### FAMILY-042：无法远程撤回已见内容

产品可以停止服务端访问、撤销令牌、删除受控缓存和尽力清理通知，但不能承诺删除成员已经截图、导出、抄录或在离线设备解密的内容。邀请确认、成员移除和隐私文案必须使用这一真实边界；OQ-006 关闭前不声称端到端撤销。

### FAMILY-043：离线写入处理

移除前服务端已 acknowledged 的操作继续有效；移除后上传的 mutation rejected_forbidden，本地只保留到用户确认删除家庭缓存或完成允许的诊断导出。禁止：

- 重新登录后自动重试到个人空间；
- 通过改 spaceId 规避权限；
- 将家庭附件变成个人附件；
- 把拒绝当作普通字段冲突让用户“选择本机版本”。

## 6. 所有权转移

### FAMILY-050：发起

- 目标必须是 active member，不能有待退出/移除或账号删除状态；
- 发起 owner 近期重新认证；
- 一次家庭只能有一个 awaiting_target 转移；
- 提案 24 小时后过期，owner 可提前取消；
- 目标收到不含家庭内容的服务通知，在 App 内查看职责和影响；
- 发起不立即降低 owner 权限。

### FAMILY-051：接受

目标近期重新认证并明确接受后，服务端锁定空间及两条 membership，重新验证 base 版本、目标状态和无并行删除，再在一个事务：

1. 原 owner role 改 member；
2. 目标 role 改 owner；
3. OwnershipTransfer 置 accepted；
4. 增加空间版本与 ServerSequence；
5. 写两条角色变化及转移审计。

任一步失败全部回滚。拒绝、过期或取消保持原 owner；目标不响应不能让家庭失去管理者。

## 7. 记录移入家庭

### FAMILY-060：预检

只有个人空间 owner 且为目标家庭 active member 的用户可以发起。预检固定 base 版本并展示：

- 标题、类型、敏感状态和所有成员可见后果；
- 清单项目、完成历史、周期历史、库存流水和低库存状态等会随聚合共享的内容；
- 附件数量/大小和密钥重归属；
- 分类、标签、模板/清单来源和 RecordLink；
- 提醒计划、当前稍后提醒和 initiator 的设备订阅；
- 未同步/冲突、回收站/归档和目标容量；
- 私人 AuditEvent 不随内容公开，家庭审计从“某成员共享此记录”开始。

回收站记录、未解决冲突、正在恢复/删除的空间或损坏附件默认不能移动，必须先解决。

### FAMILY-061：分类、标签和关联映射

- 没有同规范化名称时默认在目标创建独立分类/标签；
- 有同名时让用户选择复用目标、重命名新建或移除关系，不静默假设语义相同；
- RecordLink 的目标也被选中一起移动时保持；
- 未一起移动的个人/其他家庭目标必须选择断开关系或取消，不能留下跨空间引用；
- 清单模板不是 Record，不随实例移动；移动后的清单保持结构快照，可由家庭成员另存家庭模板；
- linkedHouseholdItemId 只有关联物品一起移动时保留，否则断开并说明采购项内容仍在。

### FAMILY-062：确认和提交

```text
preflight
→ awaiting_confirmation
→ transferring
→ committed
  ├→ failed_retryable
  └→ rolled_back
```

确认前重新验证成员、空间和记录版本。逻辑提交必须保证：

- source 写入 move tombstone，target 保持同一 record/aggregate ID；
- 所有聚合子对象、分类标签映射、合法关联和提醒计划属于 target；
- 附件内容重新授权/加密和哈希验证完成；
- 目标 committed 前不可见，来源在 committed 前保持唯一可写；
- initiator 默认创建 active ReminderSubscription，其他成员不自动订阅；
- source 记录私有移动审计，target 记录 server_verified 共享审计；
- 所有设备重新同步并对账通知。

物理附件传输失败进入 failed_retryable，用户可继续或回滚；不得留下两份可写记录或半数附件可见的家庭记录。

### FAMILY-063：敏感记录加强确认

移动 sensitive 或 aiAccess=denied 记录时再次说明：所有 active 成员解锁后都能查看；通知仍完全隐藏，AI 禁止状态保留。只有用户在移动完成后的独立高风险动作中才能放宽，不能把移动确认顺带当作 AI 授权。

## 8. 移出与复制到个人空间

### FAMILY-070：owner 移出

家庭首期只有 owner 可以把记录移动到自己的个人空间：

- 预检目标个人空间、其他成员失去访问、关联断开、附件、提醒和冲突；
- 未解决的成员写入或附件上传必须先同步/取消；
- 使用与 FAMILY-060～062 相同的原子移动协调；
- 家庭保留内容最小 move tombstone 和审计，不保留可浏览正文副本；
- 目标个人空间携带领域聚合历史，但不携带完整家庭 AuditEvent 或成员显示名；
- 其他成员的 ReminderSubscription 取消，owner 的订阅转换为个人设备选择。

### FAMILY-071：复制为个人记录

任一 active 成员可以对可见家庭记录发起明确“复制到个人空间”，使用 BR-030 的类型适配复制规则：

- 新记录及所有可复制子对象使用新 ID；
- 不复制家庭审计、membership、订阅、完成/提醒投递历史或跨空间关联；
- 家庭物品清除库存流水并要求确认新期初数量；
- 清单清除项目完成状态和绝对提醒；
- 重要日期重新确认具体日期/起始年份；
- sensitive 与 aiAccess 采用更严格值，不因进入个人空间自动放宽；
- 原家庭记录和其他成员不受影响。

移动和复制使用不同名称、图标、影响说明和命令，不能用同一按钮根据权限偷偷改变语义。

## 9. 共同处理与冲突

### FAMILY-080：复用领域同步规则

成员共同处理严格使用 SYNC-040～SYNC-043：

- 不同清单项目独立合并，同一项目字段冲突；
- 勾选/取消按服务端接受顺序保留操作历史；
- 同一周期完成与跳过要求解决；
- RecurrenceSegment 并发编辑整体冲突，不拼接；
- 库存不可变流水合并并由服务端 ledgerSequence 排序；会造成负库存的后操作拒绝；
- adjust 基准改变必须重新确认；
- 删除墓碑、成员失权和更严格隐私优先。

页面不得使用普通“最后写入胜出”掩盖成员修改。

### FAMILY-081：高风险串行

同一家庭的所有权转移、成员移除、空间删除、完整导出和跨空间移动在服务端使用空间级互斥或等价串行化。普通不同记录编辑不因一个高风险预览长期锁住；只在最终提交的短事务重新验证版本。

### FAMILY-082：成员归因

共同操作显示实际 actor：

- 周期完成/跳过、清单勾选、库存流水、归档/回收站和规则编辑记录 Account ID 与服务端顺序；
- 同一 Account 多设备仍是同一成员，但诊断可以显示设备；
- 离开成员显示“已离开成员”及允许的当时名称快照，不把历史归给 owner；
- 显示名变化不改写 actor ID；
- 归因不等于内容所有权或撤销权限。

## 10. 家庭提醒与订阅

### FAMILY-090：默认订阅

- 家庭 ReminderPlan 属于业务记录，不属于创建者；
- 新建家庭提醒时，创建/移动该计划的成员默认订阅 all_active_devices；
- 其他成员不因加入家庭或记录存在而自动收到全部提醒；
- 每位成员可以主动订阅/退订、选择全部或自己的部分设备；
- owner 首期不能强制其他成员订阅；assignment 来源字段为后续明确分工预留；
- 家庭中已有低库存事件时，成员主动订阅只影响未来 episode，不补发已确认周期。

### FAMILY-091：共享状态处理

任一有权成员完成/跳过共享周期、完成清单、知道了低库存或改变记录状态后：

- 业务 mutation 对所有成员同步；
- 所有 ReminderSubscription 的未来重复催促按来源规则取消；
- 已展示通知只能尽力清理；
- 同步延迟时可能多成员同时看到首次提醒，不承诺全局恰好一次；
- “稍后提醒”默认只创建操作成员自己的订阅投递，不改其他成员提醒或业务时间。

### FAMILY-092：成员变化

成员 leaving/removing 时，在同一服务端逻辑操作取消其所有 active ReminderSubscription、推送目标和待发送服务通知。再次加入不恢复旧订阅；由成员重新选择。所有权转移不自动改变双方订阅。

## 11. 家庭操作记录

### FAMILY-100：必须记录的事件

服务端至少记录：

- 家庭创建/重命名、邀请创建/撤销/接受；
- 成员加入/退出/移除、所有权转移；
- 记录移入/移出、永久删除、批量删除、清空回收站；
- sensitive/aiAccess 放宽；
- 家庭删除计划、取消和完成；
- 记录创建/编辑字段类别、归档/回收站/恢复；
- 周期完成/跳过、清单处理和库存流水动作类别。

summary 只含对象类型/ID、字段类别、项目数量或库存动作类别，不复制标题、正文、清单内容、精确数量或附件名。成员可从有权限的业务对象查看具体内容。

### FAMILY-101：可信、可见和不可改

- 权限、成员和高风险事件只能在对应服务端事务成功后生成 server_verified AuditEvent；
- 客户端 clientMutationId 用于关联，不允许上传自称成功的审计正文；
- active owner/member 都可按时间和对象类型查看；
- 普通成员和 owner 都不能编辑或删除单条审计；
- 删除业务记录后审计只保留最小对象类型/ID和动作，不保留可恢复内容；
- 显示成员当前名称或受控快照，账号已删时显示“已删除账号”。

### FAMILY-102：保留

家庭 active 时保留用户可见审计；家庭删除后，含生活内容的辅助快照随内容清理，最小高风险审计/同步收据默认保留 400 天，用于安全、争议和防旧设备复活，随后匿名化或删除。法律要求不同期限时以完成地区审阅后的合规规范为准，并在删除确认中准确披露。

## 12. 家庭删除

### FAMILY-110：计划删除

owner 发起前必须：

1. 完成近期重新认证；
2. 查看记录/附件/回收站、成员、未同步设备、冲突和云备份影响；
3. 向成员提供完整家庭导出由 owner 发起、以及各成员复制允许记录的机会；
4. 解决进行中的所有权转移/成员移除/跨空间移动；
5. 输入家庭名称或本地化确认词。

确认后进入 deletion_scheduled，默认 7 天后永久删除；页面显示精确日期，通知全部成员，暂停新写入、邀请和未来提醒。owner 在截止前可取消并触发各设备重新同步/对账；取消后只从当前时点恢复未来提醒，不补发暂停期间已经过去的通知。

### FAMILY-111：到期删除

到期后服务端：

1. 锁定空间并再次检查 generation；
2. 置 deleting，拒绝全部普通请求；
3. 永久删除记录聚合、模板、分类标签和可见附件引用；
4. 擦除无其他合法引用的对象内容和云备份；
5. 创建空间/实体 Tombstone 与最小审计收据；
6. 取消 membership、Invitation、OwnershipTransfer、ReminderSubscription、推送和会话授权；
7. 置 deleted 并通知在线设备清理本地家庭数据。

任一步失败保持 deleting 并由服务端幂等继续，不能回到一半可写。删除不会把内容复制给 owner 或 member。

### FAMILY-112：删除边界

- 无法保证擦除成员已经导出、截图、抄录或离线解密的副本；
- 个人空间和成员账号不删除；
- 家庭记录的个人复制因使用新 ID 和独立生命周期而不删除；
- 第三方系统分享的文件不在产品控制范围；
- 法定最小记录不含可恢复生活正文，按 FAMILY-102 与合规规范处理。

## 13. 故障、离线和安全

### FAMILY-120：失败恢复

| 失败 | 处理 |
| --- | --- |
| 邀请创建响应丢失 | 同 mutation ID 返回原邀请；不新建 token。 |
| 接受时满员/已撤销 | 不创建 membership，显示受控状态。 |
| 所有权目标未响应 | 到期保持原 owner。 |
| 移动时附件失败 | 来源唯一可写；继续或完整回滚。 |
| 成员离线期间被移除 | 服务端立即拒绝；联网后清理缓存。 |
| deletion_scheduled 设备离线编辑 | 上传时拒绝，允许个人诊断导出，不合入空间。 |
| 审计写入失败 | 高风险事务整体失败；普通业务至少写可靠 outbox 后才确认。 |
| 未知权限/Schema | 客户端只读保护并要求升级。 |

### FAMILY-121：令牌和最小化

- Invitation token、AccountSession、附件签名 URL 和推送令牌只进入适用安全存储/短期内存；
- 链接预览、远程 push 和普通日志不含家庭名、成员名单、记录标题或正文；
- 服务端所有列表按 membership 过滤并防对象 ID 越权；
- 家庭导出需要 owner 近期重新认证，生成文件按未加密导出风险说明；
- 支持人员不能把添加自己为成员当作排障方式；
- 防滥用冻结邀请不改变现有成员读取个人/家庭本地副本的正常规则。

### FAMILY-122：E2EE 未决边界

P2 开始实现前必须关闭 OQ-006。默认设计使用 TLS 与服务端存储加密，不承诺端到端加密；若改为 E2EE，必须重新设计成员撤销、密钥轮换、搜索、AI 上下文、审计、云备份、附件和恢复，不能只在接口增加一个密文字段。

## 14. 实施与验收测试矩阵

### FAMILY-130：权限

对 FAMILY-020 每个单元测试 owner/member、active/non-active、在线/离线和旧缓存；使用直接 API 请求验证服务端，不只测按钮隐藏。重点覆盖 member 可 trash 但不可 purge、任何成员可收紧但只有 owner 可放宽保护。

### FAMILY-131：邀请和成员竞态

覆盖：接受/撤销同到达、邀请到期边界、绑定账号不符、满员、重复接受、owner 同时移除、成员离线写入与移除先后、再次邀请。每一结果都验证 membership 唯一、审计和无内容泄漏。

### FAMILY-132：所有权与删除

覆盖转移接受/拒绝/过期/取消、目标同步退出、并行删除、两请求重复和服务中断；任何时间查询都只能有一个 owner。家庭删除覆盖 7 天边界、取消、所有设备离线、幂等擦除和个人空间不受影响。

### FAMILY-133：跨空间移动

五种记录分别覆盖分类标签同名、关系一起移动/断开、附件失败、敏感状态、提醒订阅、未解决冲突、回收站和回滚。验证任一观察点至多一个空间可写、ID 保持、个人审计不泄漏、家庭审计从共享开始。

### FAMILY-134：共同处理和提醒

至少三账号、每账号两设备交错执行清单勾选、周期完成/跳过、库存买入/使用/调整、规则编辑、trash/restore 和 snooze。验证 SYNC-042 冲突、ledgerSequence、跨成员提醒取消及“稍后提醒只影响本人”。

### FAMILY-135：移除与数据边界

模拟被移除设备长期离线、已下载附件、未上传 mutation、通知残留、导出和截图边界；验证服务端立即失权、本地尽力清理、旧内容不重新上传，且产品没有虚假“远程完全擦除”声明。
