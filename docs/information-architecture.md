# 生活有谱信息架构

> 项目代号：`life-book` · 版本：v1.1 · 更新日期：2026-07-26 · 状态：体验结构基线
>
> 权威范围：导航层级、页面编号、内容归属、跨入口规则和阶段页面清单
>
> 不负责：页面视觉布局、字段业务规则、数据表和具体路由框架
>
> 依赖文档：[产品需求基线](product-features.md)、[产品路线图](roadmap.md)、[术语表](glossary.md)

## 1. 架构原则

1. **从需要关注的内容开始**：“今天”是默认首页，不以统计图或完成率作为首屏。
2. **按用户心智分入口**：全部记录在“生活簿”，物品库存集中在“家中”，设置与数据控制在“我的”。
3. **一个全局创建入口**：所有主要视图使用同一全局加号，避免不同页面产生不一致的创建规则。
4. **聚合不是复制**：“今天”和“家中”可以展示同一记录的关注项或快捷入口，但详情只有一个权威对象。
5. **未来空间不污染 P0**：P0 只有默认个人空间，不展示没有选择价值的空间切换器；家庭空间上线后再出现空间上下文。
6. **高风险操作集中且可追溯**：备份、恢复、永久删除和清除本机数据位于清楚的数据管理区域，不藏在普通编辑动作中。
7. **敏感内容先解锁后展示**：深链接、系统通知和最近任务恢复都先经过应用锁与隐私检查。

### 2.2 底部导航规则

- 固定顺序为：今天、生活簿、家中、我的；全局加号视觉上独立但属于主框架。
- 首次启动、普通冷启动和完成应用锁后默认进入“今天”。
- 切换标签页应保留各自导航栈、筛选条件和合理的滚动位置；App 被系统终止后只恢复安全且非敏感的结构状态。
- 再次点击当前标签返回该标签根页面；若已经在根页面，则滚动到顶部。
- 全局加号在四个根标签和常规列表页面可见；编辑、确认、高风险操作和系统文件选择器中不重复显示。
- P0 不显示空间切换器、账号头像或无法使用的同步状态。

## 3. 页面编号规则

- 页面和系统界面使用稳定 `SCR-*` 编号。
- 页面编号表示用户能识别的界面，不等同于代码文件；同一页面的加载、空、错误和离线状态不另起编号。
- 弹窗只在拥有独立业务结果或高风险确认时获得编号；简单菜单属于其宿主页面。
- 页面被替代时保留编号并在本文件标记，不重新分配给新页面。
- 页面规格、用户流程、验收场景和自动化测试使用本编号追溯。

### 6.2 归档与删除可见性

- 归档记录默认只在归档内容和显式包含归档的搜索中出现。
- 删除记录只在回收站出现，不参与今天、家中、默认搜索和提醒。
- 永久删除完成后，旧深链接进入不可用状态页，不显示已删除内容。
- 清单模板删除不影响既有实例；实例详情不再显示已删除模板的可点击链接。

### 6.3 敏感内容

- 未解锁时任何页面不渲染敏感标题、正文、缩略图或最近搜索词。
- 解锁后仍遵循用户设置的列表预览策略；进入详情可以再次要求认证的扩展点保留。
- 系统通知和分享预览使用最严格的“全局设置 × 单条敏感状态”结果。
- App 进入后台时主内容被安全遮罩，系统任务切换缩略图不得含生活内容。

## 7. 全局页面状态模型

每个依赖数据的页面必须设计以下适用状态，页面规格不得只画有数据的理想状态：

| 状态 | 要求 |
| --- | --- |
| 初始加载 | 300 毫秒内完成时避免闪烁；更久时使用结构占位或明确进度。 |
| 空状态 | 说明当前为什么为空并提供真实下一步，不创建虚假示例。 |
| 部分数据 | 个别附件或派生索引失败时保留其余可用内容并标记问题。 |
| 离线 | 本地功能继续可用；只在用户触发在线能力时显示局部状态。 |
| 权限缺失 | 说明功能影响和修复入口，不阻塞无关操作。 |
| 服务降级 | 智能、同步或遥测故障只影响对应区域。 |
| 可重试错误 | 保留输入/上下文，明确重试与替代路径。 |
| 不可恢复错误 | 停止破坏性操作，提供诊断标识和支持入口。 |
| 锁定 | 不先渲染敏感内容再覆盖；先认证再加载。 |

## 8. 返回、取消和未保存内容

- 系统返回、手势返回和页面取消使用同一语义。
- 表单没有修改时直接返回；存在修改时提供“继续编辑 / 放弃更改”。
- 智能创建当前输入在超时、重试和转手动时保留；主动退出并确认放弃后清除。
- 系统文件选择器取消后回到原页面，不把取消显示为错误。
- 高风险操作不能通过返回手势绕过最终确认，也不能在确认前改变数据。
- 创建成功后再按系统返回不得重新提交同一记录。

## 11. 深链接和通知路由

逻辑深链接使用版本化资源语义，不把页面组件名写入公共链接：

```text
lifebook://v1/records/{recordId}
lifebook://v1/occurrences/{occurrenceId}
lifebook://v1/reminders/{reminderInstanceId}
lifebook://v1/settings/notifications
lifebook://v1/settings/backup
```

约束：

- 外部链接只包含不透明 ID，不包含标题、正文或日期内容；
- P0 找不到对象时显示状态页并允许返回今天；
- P2 链接必须验证当前账号和空间权限；
- 版本未知时进入安全的升级或不支持页面；
- 通知动作不依赖先打开页面，但动作完成后深链接必须反映最新状态。

## 12. 变更影响

新增或移动页面前必须检查：

- 是否改变 PR-005 的四个主导航含义；
- 是否让同一对象出现两个可独立编辑的副本；
- 是否在 P0 暴露 P1/P2 空入口；
- 是否有加载、空、离线、权限、故障和锁定状态；
- 是否需要新的深链接、通知动作或返回规则；
- 是否影响敏感内容、空间上下文和高风险确认；
- 是否已在用户流程和页面规格中使用同一 `SCR-*` 编号。
