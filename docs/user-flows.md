# 生活有谱用户流程规范

> 项目代号：`life-book` · 版本：v1.0 · 更新日期：2026-07-26 · 状态：体验流程基线
>
> 权威范围：P0/P1/P2 端到端任务步骤、页面跳转、分支、提交点、取消、失败与恢复路径
>
> 不负责：页面布局、视觉样式、领域算法、接口字段、数据库事务实现和阶段归属
>
> 依赖文档：[信息架构](information-architecture.md)、[产品需求基线](product-features.md)、[业务规则](business-rules.md)、[时间规则](time-and-recurrence.md)、[提醒规范](reminders-and-notifications.md)、[数据生命周期](data-lifecycle.md)、[智能创建契约](ai-creation-contract.md)、[账号与同步](account-and-sync.md)、[家庭共享](family-sharing.md)

页面用 `SCR-*`，流程用稳定 `FLOW-*`。本文件说明用户如何完成任务；数据是否有效、何时产生业务事实仍以对应专项规则为准。

## 1. 跨流程约束

### FLOW-001：提交点必须可辨认

- 查看、预览、智能生成、追问、文件选择和高风险影响分析都不是业务提交；
- 创建/保存按钮只在同步校验通过时可执行，并在点击后防重复；
- 领域事务成功后才能显示成功，不以网络请求发出、通知调度或文件复制开始代替；
- P1/P2 离线时区分“已保存在本机”和“已同步”；
- 取消和系统返回在提交前不改变业务事实。

### FLOW-002：未保存内容

- 未改动直接返回；已改动时提供“继续编辑 / 放弃更改”；
- 智能输入在超时、重试、追问和转手动时保留；
- 文件选择器取消回到原表单；附件暂存失败不清空其他字段；
- App 被系统终止后，普通表单是否恢复取决于加密草稿能力；P0 不承诺跨进程恢复智能原文；
- 高风险确认关闭即视为取消，不能后台继续。

### FLOW-003：错误层级

| 层级 | 展示位置 | 恢复 |
| --- | --- | --- |
| 字段校验 | 字段旁和首个错误摘要 | 修改字段，其他输入保留 |
| 局部能力 | 附件、通知、智能、同步模块内 | 重试或使用不依赖该能力的路径 |
| 当前操作 | 页面级错误 | 保留上下文，重试/取消 |
| 数据完整性 | 阻断页面 | 停止写入，诊断、备份/导出或恢复 |

错误消息使用受控原因，不展示堆栈、供应商原文或敏感内容。

### FLOW-004：锁与深链接

系统通知、外部链接和进程恢复统一经过：

```text
解析无内容路由
→ SCR-001 数据准备
→ 需要时 SCR-002 解锁
→ 验证空间、权限、对象和动作现状
→ 当前有效页面 / 可解释失效状态
```

认证前不预渲染敏感内容；解锁取消回到安全页面，不执行通知动作。

## 2. 启动、空状态与渐进引导

### FLOW-010：首次启动

**入口**：首次安装后打开 App。**页面**：SCR-001 → SCR-003 → SCR-010。

1. 创建 Installation、LocalActor、空默认个人空间和设备主密钥；
2. 打开加密数据库并运行完整性/版本检查；
3. 不请求通知、照片、相机、麦克风或生物识别权限；
4. 直接进入“今天”空状态，说明可以一句话或手动记第一件事；
5. 用户点全局加号进入 SCR-100，也可浏览生活簿、家中和我的。

初始化失败时停在 SCR-001，提供重试、诊断 ID 和安全清除空初始化；检测到已有数据时禁止以“首次失败”为由清空。

### FLOW-011：普通启动与迁移

1. 先建立安全遮罩，读取应用锁状态；
2. 需要解锁时进入 SCR-002；
3. 打开数据库并检查 Schema、恢复标记和迁移；
4. 迁移在受保护路径完成并验证，再运行索引/提醒对账；
5. 快速路径直接进入 SCR-010，耗时任务在 SCR-001 显示真实阶段；
6. 非关键索引/提醒重建可进入主框架后继续，明确局部状态。

迁移失败不得创建空库；进入只读恢复页，提供诊断、备份恢复或尽可能导出。

### FLOW-012：渐进权限

- 第一次保存包含提醒计划的记录：先保存，再由 SCR-901 解释并请求通知权限；拒绝时记录仍成功；
- 第一次添加图片/文件：说明选择范围后调用系统选择器；拒绝只影响附件；
- 用户主动开启应用锁：在 SCR-451 说明失败恢复后调用系统认证；
- P1 主动录音才请求麦克风；
- 权限已经拒绝时不重复弹系统框，只提供 SCR-411 设置入口。

## 3. 通用手动创建与编辑

### FLOW-020：选择创建类型

**入口**：任意主列表全局加号。**页面**：SCR-100 → SCR-110～115。

1. SCR-100 默认聚焦一句话输入，同时持续显示五种手动入口；
2. 用户选择类型后进入相应空表单；
3. 从“家中”发起可预选家庭物品，从模板库发起可预选清单；其余字段不暗中预填；
4. 返回且无输入直接取消；有输入按 FLOW-002；
5. 保存使用 FLOW-021。

### FLOW-021：校验并保存记录

```text
编辑字段
→ 即时局部校验
→ 点击保存
→ 完整领域/时间/附件校验
→ 一次领域事务
→ SCR-104（创建）或原详情（编辑）
→ 异步索引和提醒对账
```

- 第一次提交失败定位字段并保留输入；
- 重复点击使用同一页面提交键，不能创建两条；
- 记录事务成功但提醒/索引副作用失败时显示“记录已保存”及局部修复状态；
- 创建成功页可“查看详情 / 再记一件 / 回到今天”，系统返回不重复提交；
- 编辑成功回原详情并说清更新类别，不展示 SCR-104。

### FLOW-022：分类、标签和附件

- SCR-118 选择一个分类、最多 20 个标签；快速新建按规范化名称检查重复；
- 删除选择只改变当前表单关系，不删除分类/标签本身；
- SCR-119 仅在备忘/家庭物品 P0 开放，选中文件先进入加密暂存；
- 单附件失败允许重试或移除失败附件，其他字段保留；
- 用户取消整个表单，暂存附件按 BR-023 清理；
- 保存时附件元数据与记录逻辑提交一致，必要附件失败不得出现假成功。

### FLOW-023：编辑、归档和复制

**入口**：详情 → SCR-300。

- 编辑进入对应表单，固定 base revision；保存前对象已改变时重新加载/解决冲突；
- 归档直接预览未来提醒影响，确认后回生活簿并提供撤销；
- 解除归档从当前时点重建未来提醒，不补发历史；
- 复制进入类型适配确认，清除 BR-030 禁止复制的状态；
- P0 只显示路线图已开放的复制能力，不能因底层字段存在提前暴露。

## 4. 智能创建

### FLOW-030：首次智能创建

**页面**：SCR-100 → SCR-101 → SCR-102/103/105 → SCR-104。

1. 用户输入 1–4,000 码点文字并点“帮我整理”；
2. 首次进入 SCR-101，展示发送本次文字、固定参考上下文、不发送其他记录、确认前不写入和手动替代；
3. 同意后固定 referenceContext 并提交 requestId；
4. 取消使 generation 失效，迟到响应丢弃；
5. 结果按 FLOW-031～033 分流。

拒绝数据说明回 SCR-100，原文保留，五种手动入口仍可用。

### FLOW-031：直接草稿与确认

- 合法 draft 经过客户端 Schema/领域二次校验后进入 SCR-103；
- 正常字段展示值，inferred/default 标来源；时间、重复预览、提醒、库存变化完整展开；
- 用户编辑字段变 confirmed_edit 并重新确定性校验，不自动调用模型；
- 重新生成保留当前草稿直到新草稿成功；
- 确认调用与手动创建同一领域命令；
- 保存失败留在 SCR-103，可重试保存且不重新耗用模型；
- 取消不创建回收站、提醒或库存流水。

### FLOW-032：一次追问

- clarification_required 进入 SCR-102，只显示一个概念和安全选项；
- 回答后以 attempt=1 和原固定上下文提交；
- 得到 draft 转 SCR-103；仍歧义、再次追问、用户取消或当前不支持则转 FLOW-033；
- 用户随时选择一种手动类型，原文和可安全映射的回答进入表单；
- 不能用第二个弹窗伪装成第二轮追问。

### FLOW-033：无法生成与服务故障

| 结果 | 路径 |
| --- | --- |
| unrecognized | SCR-105 选择手动类型；原文保留 |
| multiple_intents | 展示检测到的类型摘要，只让用户选择一条重新处理/手动，不静默丢意图 |
| unsupported | 说明具体当前限制，进入最近手动路径 |
| content_refused | 不显示内部规则，允许本地手动输入 |
| 网络/供应商错误 | 最多一次安全自动重试；之后手动重试/转手动 |
| 额度不足/功能关闭 | 展示状态，不循环请求，手动功能继续 |
| 契约版本旧 | 提示升级或转手动，不保存未知字段 |

所有路径在用户明确放弃前保留当前输入；服务端错误不触发数据库或通知。

## 5. 重复事项

### FLOW-040：创建规则

**页面**：SCR-110 → SCR-116 → SCR-117 → SCR-104。

1. 输入标题、开始日期与全天/时间语义；
2. SCR-116 选择 daily/weekly/monthly/yearly、interval、适用星期/月日和结束条件；
3. 即时显示未来 5 项，非法日期/空规则不能保存；
4. 可在 SCR-117 设置 at_schedule/提前提醒和明确重复催促；
5. 返回表单后再次显示人类可读规则；
6. 保存创建 Record + RecurrenceSegment + ReminderPlan。

月末 31、2 月 29、DST 和 count 预览严格使用 REC-*；不支持“最后一天”时引导调整而不近似。

### FLOW-041：处理周期实例

**入口**：SCR-010、SCR-200、SCR-201 或 SCR-900。

- pending 可完成、跳过、稍后或打开；
- 完成/跳过先验证 occurrenceKey 和当前状态，重复动作返回既有结果；
- 完成与已跳过冲突时打开 SCR-201，不后台覆盖；
- 稍后只改变提醒实例，不改原 ScheduleSpec；
- 成功后今天卡片刷新，取消该实例未来催促，历史仍可见；
- 过去未物化候选按 BR-041 分组，不一次渲染无限卡片。

### FLOW-042：修改规则或单次

1. 从 SCR-201 修改时间/状态时选择“仅本次”；
2. 从 SCR-200/110 修改规则时进入 SCR-303；
3. 选择“本次及以后”，预览切分点、未来 5 项、结束次数和提醒变化；
4. 确认后原段关闭、新段创建，历史不变；
5. 影响已处理实例或产生空规则时报错并返回编辑；
6. 事务成功后取消旧未来系统调度并对账。

P0 不提供“修改过去所有实例”。

## 6. 清单与模板

### FLOW-050：创建和处理清单

**页面**：SCR-111 → SCR-210。

- 选择 general/shopping，编辑分组和项目、可选数量/单位、截止和提醒；
- 拖动排序只改变 SortKey；删除有内容项目提供撤销；
- 勾选项目写入项目完成状态，全部有效项目完成时清单派生 completed；
- 取消任一完成自动重新打开；
- 完成清单取消未来截止提醒，重新打开按 BR-053 处理；
- 系统通知只允许打开/稍后，不在锁屏一键完成整个清单。

### FLOW-051：从模板创建

**页面**：SCR-023/211 → SCR-111 → SCR-210。

1. 预览模板结构和相对截止/提醒建议；
2. 创建独立清单草稿，项目未完成；
3. 把相对建议计算为绝对值并在 SCR-111 确认；
4. 保存后模板与实例互不影响；
5. 模板后来修改/删除不改变既有实例。

### FLOW-052：另存模板、复制和删除模板

- 清单详情“另存模板”只复制结构和允许的相对建议；
- 清除完成、绝对截止、提醒实例、附件和空间成员；
- 编辑模板不更新实例；
- 删除模板前展示使用次数，仅删除模板；
- 复制清单使用 BR-030，和另存模板使用不同动作名称。

## 7. 备忘与附件

### FLOW-060：创建/编辑备忘

**页面**：SCR-113 → SCR-220。

- 标题/正文至少形成一个有效内容；手动仅正文时让用户确认建议标题或使用可编辑通用标题；
- 可添加 P0 允许附件和一个或多个绝对提醒；
- 知道了/稍后只处理提醒，备忘没有完成、跳过或逾期状态；
- 修改正文不改变提醒；归档/删除取消未来提醒；
- 置顶只影响适用列表，不提高今天紧急度。

### FLOW-061：查看和修复附件

**页面**：SCR-220/240 → SCR-304。

- 未解锁敏感附件显示遮罩；
- available 才可打开/分享；processing 显示进度，可取消；
- missing/corrupt 显示原因和重新选择入口，记录其余内容可用；
- 替换创建新 Attachment，不篡改旧哈希；
- 分享前再次应用敏感预览和未加密外发说明。

## 8. 重要日期

### FLOW-070：创建重要日期

**页面**：SCR-114 → SCR-117 → SCR-230。

1. 分别选择 eventKind、calendarSystem、recurrenceMode 和 dateValue；
2. P0 calendarSystem 固定 gregorian，农历入口不出现；从智能农历意图转备忘替代；
3. 可填 startYear，并选择 counterDisplay auto/hidden；
4. 添加多个提前/当天提醒，重复时间去重；
5. 预览下一次公历显示、还有几天及适用年龄/周年；
6. 保存后日期是事实，不出现完成/跳过。

### FLOW-071：查看和处理提醒

- SCR-010 今日事实与同日提醒合并一张卡；
- 提前提醒“知道了”不隐藏即将到来的日期；
- 当天事实保留到本地自然日结束；
- 稍后可越过发生日，文案切换为回顾；
- 修改日期使旧 occurrence 失效时取消旧提醒，重新预览未来。

## 9. 家庭物品、库存与采购

### FLOW-080：创建家庭物品

**页面**：SCR-115 → SCR-240。

1. 输入名称、非负 initialQuantity、单位、可选阈值、位置/说明/图片；
2. 显示期初 `0 + initial = current`；
3. 若 `initial <= threshold`，说明保存后立即属于低库存，但创建表单已看见所以不发冗余系统通知；
4. 保存事务创建 Record、HouseholdItemDetail、opening 流水、缓存和适用 episode；
5. 图片处理失败可移除后保存，必要数据失败不产生半条物品。

### FLOW-081：库存操作

**页面**：SCR-240 → SCR-241 → SCR-240。

- 选择买入/使用/调整/报废/丢失；
- 输入正数量或调整目标、实际发生时间和可选备注；
- 提交前显示 before、delta、after 与阈值变化；
- after < 0 时阻止并建议“调整为实际数量”；
- 保存只追加流水、更新缓存和 episode，原流水不编辑；
- 修正旧流水从详情发起 adjust，并显示 correctionOfId 关系；
- 网络/通知失败不重复写流水。

### FLOW-082：低库存与采购清单

**入口**：SCR-010/030/033/240。

1. 进入 `<= threshold` 创建一次 episode，未来适用时产生一次提醒；
2. 用户点“加入采购清单”进入 SCR-034；
3. 有 shopping 清单时列出最近使用并允许选择；没有时预填新 shopping 清单确认；
4. 已有同物品未完成项目时打开它，让用户确认更新数量；
5. 默认建议购买数量按 BR-091，提交前可改；
6. 成功后 episode acknowledged，但低库存列表保留至数量恢复；
7. 采购项目完成不自动增加库存，用户另行执行买入。

## 10. 今天、搜索与整理

### FLOW-090：处理今天关注项

**页面**：SCR-010 → SCR-011/详情。

- 按逾期、待查看、今天、即将到来、需要补货分组并使用 BR-100 排序；
- 卡片说明出现原因，不显示不适用动作；
- 重复事项完成/跳过，清单打开，备忘/重要日期知道了/稍后，低库存采购/知道了；
- 同一对象多个提醒合并，详情列出；
- 动作失败刷新现状并说明，不以乐观动画掩盖冲突；
- 敏感卡片按预览设置，未解锁不读内容。

### FLOW-091：搜索

**页面**：SCR-020 → SCR-021 → 详情。

1. 输入去首尾空白查询，本地安全索引即时返回；
2. 结果按 SRCH-* 规范归一化、排名、分组和高亮；
3. 输入为空回到建议筛选，不上传查询；
4. P0 查询只在当前会话，退出页面/锁定/进程终止清除；
5. 结果过时或被删除时刷新并说明；
6. 搜索索引故障时提供重建，不伪装成“没有记录”。

### FLOW-092：筛选、归档与分类管理

- SCR-022 选择类型、分类、标签、状态、日期与排序，显示条件 chips 和一键清除；
- SCR-024 只显示归档，解除后离开当前结果；
- SCR-420 重命名/合并/删除前显示受影响记录数；
- 删除分类/标签只清关系；合并在一个事务更新关系并防重；
- 置顶在详情/列表动作切换，不改变今天排序。

## 11. 提醒和系统通知

### FLOW-100：首次保存提醒与权限

1. FLOW-021 先成功保存记录/ReminderPlan；
2. SCR-901 解释系统通知用途和拒绝影响；
3. 用户继续才显示系统权限；
