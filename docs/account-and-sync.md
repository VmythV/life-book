# 生活有谱账号与同步规范

> 项目代号：`life-book` · 版本：v1.0 · 更新日期：2026-07-26 · 状态：P1 实施基线
>
> 权威范围：可选账号、本地数据认领、设备会话、个人空间增量同步、冲突、附件传输、云备份协作、退出和账号删除
>
> 不负责：家庭角色权限、物理数据库表、HTTP 字段、加密算法参数、具体身份/云厂商和 P0 本地备份格式
>
> 依赖文档：[产品需求基线](product-features.md)、[领域模型](domain-model.md)、[业务规则](business-rules.md)、[数据生命周期](data-lifecycle.md)、[提醒规范](reminders-and-notifications.md)、[产品路线图](roadmap.md)、[未决事项](open-questions.md)

本规范落实 PR-520～PR-524，并为 PR-540～PR-545 提供同步基础。机器请求结构由 OpenAPI 唯一定义；本文只定义在任何接口实现下都必须成立的产品与领域语义。

## 1. 不变量与阶段边界

### SYNC-001：账号始终可选

- P0 不出现强制登录；P1 用户只有主动开启同步、云备份或家庭功能时才需要账号。
- 注册失败、登录过期、网络中断、同步冲突或服务停机不得阻止用户读取和编辑仍可用的本地个人数据。
- 内置智能的匿名身份与 Account 分离；登录不能偷偷上传之前的智能输入或把匿名额度历史变成生活档案。
- 账号不是本地加密备份口令的恢复渠道，除非未来形成新的产品和安全决策。

### SYNC-002：设备上的 SQLite 仍是可写副本

- 登录后本地数据库仍是 UI 与离线命令的事实源，不降级为必须联网的缓存。
- 领域写入和 SyncMutation 必须在同一本地事务提交；网络只异步传输已提交事实。
- 服务端是跨设备版本、账号、membership 和授权的权威，不直接成为本机提醒调度或搜索索引的事实源。
- 派生缓存、系统通知队列和传输临时文件不参与冲突胜负。

### SYNC-003：同步、云备份、导入和恢复不同

| 能力 | 语义 | 是否持续 | 默认冲突方式 |
| --- | --- | :---: | --- |
| 增量同步 | 传播已绑定空间的领域变化 | 是 | 基于版本和领域规则 |
| 云备份 | 服务端保存一个时间点恢复副本 | 否 | 创建新恢复世代 |
| 本地加密备份恢复 | 用 `.lifebook` 整体替换本地数据 | 否 | 恢复前暂停绑定并选择后续动作 |
| 通用导入 | 把外部结构映射成领域命令 | 否 | 预览、去重和逐项解决 |

界面必须分别显示“最后同步”和“最后备份”，不得用一次成功同步宣称已有可恢复备份。

### SYNC-004：空间和身份保持稳定

- 认领成功后个人空间、记录、子实体和附件 ID 保持不变。
- LocalActor 保留并通过 claimedByAccountId 映射到 Account，历史作者不批量改写。
- 一份当前本地数据集仍恰好只有一个默认个人空间。
- 选择仅本机时，不同时挂载账号的云端个人空间制造两个“默认个人空间”。
- 标题、正文或哈希相同不是同一记录的证据，不能据此静默去重。

### SYNC-005：服务端逐操作授权

每个 push、pull、附件和云备份操作都重新验证 AccountSession、Device、SpaceMembership、spaceId 和目标。客户端隐藏页面、缓存角色或持有旧对象都不是授权；DOM-089 始终优先。

## 2. 账号与认证

### SYNC-010：P1 认证基线

P1 首期提供经过验证的邮箱一次性验证码登录，不要求手机号和密码。认证服务通过适配器接入，具体邮件供应商由部署配置决定。未来 passkey、Apple 或 Google 登录映射到同一 Account，不新建第二套业务身份。

规则：

- 邮箱只用于认证、安全通知和用户明确订阅的服务消息；
- 验证码短期、一次性、限次，成功或过期后不可重放；
- 请求验证码的响应不暴露邮箱是否已注册；
- 添加/移除认证方式、账号删除、导出、所有权转移等高风险操作需要近期重新认证；
- 一个认证身份只能关联一个 active Account；合并账号不进入 P1 首期；
- 丢失唯一邮箱的恢复必须通过已登录设备或经正式安全流程处理，客服不得根据生活内容证明身份。

### SYNC-011：注册与登录状态

```text
signed_out
→ requesting_code
→ verifying
→ signed_in_unbound
→ signed_in_bound

verifying → retryable_error / locked_temporarily / signed_out
signed_in_* → reauthentication_required → signed_in_* / signed_out
```

验证码提交幂等；用户取消后迟到响应不得创建本地绑定。登录成功只建立 AccountSession，不代表同意上传本地内容。

### SYNC-012：会话与令牌

- 短期访问令牌和可轮换设备会话分开；具体期限由安全规范和服务配置确定。
- 刷新材料只进操作系统安全存储，不进 SQLite、日志、备份、剪贴板或遥测。
- 每次轮换使旧刷新材料失效；重复响应按会话 generation 丢弃。
- 网络离线时，已解锁的本地数据继续使用；需要服务器的页面准确显示离线。
- 服务端返回 revoked/expired 时停止 push/pull，不循环刷新，并进入 auth_required。

### SYNC-013：账号状态

| 状态 | 允许操作 |
| --- | --- |
| active | 正常账号、设备、同步、备份和家庭操作。 |
| deletion_pending | 取消删除、导出、查看影响、处理必要家庭所有权；禁止新增空间和普通内容写入服务器。 |
| deleted | 不可登录；按删除收据和法定最小保留处理。 |

账号被安全冻结等运营状态属于接口错误，不新增能修改生活内容的隐含账号状态。

## 3. 首次登录与本地数据认领

### SYNC-020：认领前分析

登录后客户端只先发送无内容的绑定查询；本地计算并展示：

- 当前个人空间记录、附件、回收站和待同步操作数量；
- 是否来自完整备份、云同步退出副本或另一个 Account；
- 云端个人空间是否存在及其粗粒度数量、最后同步和版本；
- 本机所需上传量、网络与存储空间；
- 可选动作和不可逆影响。

确认前不得上传标题、正文、清单项目、数量、附件或记录清单。

### SYNC-021：四种数据组合

| 本地 | 云端 | 默认路径 |
| --- | --- | --- |
| 空 | 空 | 用现有本地空间 ID 创建账号个人空间并绑定。 |
| 有数据 | 空 | 预览后认领现有空间，保留所有 ID 并上传。 |
| 空 | 有数据 | 在暂存数据库下载完整快照、验证后原子装载并绑定。 |
| 有数据 | 有数据 | 必须 choice_required；不得自动合并或覆盖。 |

“空”表示没有当前/归档/回收站记录、模板、用户分类标签或业务附件；只有默认空间和初始设置仍算空。

### SYNC-022：双方都有数据时的选择

用户可以：

1. **预览并合并到云端个人空间**：复用通用导入的映射/去重界面，把本地对象作为带原 ID 的候选导入；同 ID 根据来源绑定判断，同名不自动合并。
2. **备份本机后改用云端**：先提供本地加密备份，再在暂存区下载并原子替换；没有成功备份也可继续，但需加强确认。
3. **保持本机且暂不开启同步**：AccountSession 保留，DatasetBinding 为 unbound；云端个人空间不显示在普通生活簿中。
4. **取消**：保持登录或退出，均不改变本地数据。

P1 不支持两个个人空间同时在同一数据集可写，也不允许把本机数据静默追加到云端。

### SYNC-023：来源账号不一致

如果 provenanceAccountId 与当前 Account 不同：

- 禁止直接认领或上传；
- 展示“这份数据来自另一个账号”，不泄露对方邮箱或显示名；
- 允许退出并登录原账号、保持仅本机、导出后用通用导入创建新 ID，或清除本机数据；
- 即使用户能解锁设备，也不能借认领绕过家庭/账号访问控制；
- 客服不能后台改 provenance 作为普通修复。

### SYNC-024：绑定状态机

```text
unbound
→ analyzing
→ choice_required
→ binding
→ bound
   ├→ paused
   ├→ auth_required
   └→ detaching → unbound

analyzing/binding → retryable_error → choice_required
```

- binding 使用 bindingGeneration 隔离迟到响应；
- 上传前在本地创建设备加密检查点；
- 每一步记录 lastCompletedStep，可在崩溃后继续或回滚；
- 只有服务器确认空间、membership 和基线快照后进入 bound；
- 失败保持原数据库可用，不留下半绑定空间或重复 ID。

## 4. 同步引擎

### SYNC-030：每空间独立状态

```text
disabled
→ initializing
→ idle ⇄ syncing
          ├→ offline_queued
          ├→ auth_required
          ├→ upgrade_required
          └→ integrity_blocked
```

冲突是实体级 SyncConflict，不把整个空间变成永久 conflict 状态。一个损坏附件或一个正文冲突不得阻塞无关实体；鉴权、未知版本和空间完整性错误可以阻塞该空间。

### SYNC-031：本地提交

每个可同步领域命令在同一事务中：

1. 校验当前本地 revision 与空间；
2. 写入领域实体和历史；
3. 写入唯一 clientMutationId 的 pending SyncMutation；
4. 写入提醒/索引/附件等本地副作用任务；
5. 提交后立即更新 UI 为“已保存在本机”；
6. 网络任务稍后把状态更新为“等待同步”或“已同步”。

撤销如果已经成为独立业务事实，就创建反向领域命令和新 mutation，不删除已经发送的 outbox 项。

### SYNC-032：push 协议语义

客户端按空间和本地提交顺序发送，每批最多 100 个 mutation 或 1 MiB 非附件负载，以先达到者为准。每项携带领域模型 §16.6 定义的身份、操作、baseServerVersion 和 payloadVersion。

服务端逐项：

1. 验证会话、设备、active membership、空间和能力版本；
2. 按 clientMutationId 查找既有结果并幂等返回；
3. 验证 baseServerVersion、墓碑和领域不变量；
4. 在一个服务端事务应用领域改变、分配 entity serverVersion 和 space ServerSequence；
5. 生成必要审计、变更记录和附件任务；
6. 返回 acknowledged、conflict 或受控拒绝。

批次传输失败不表示项失败；客户端使用相同 mutation ID 重试。服务端不得部分应用一个领域 mutation。

### SYNC-033：mutation 状态

```text
pending → sending → acknowledged
                   ├→ conflict
                   ├→ retry_wait → sending
                   ├→ rejected_forbidden
                   └→ rejected_version
```

- sending 在进程终止后恢复为 pending；
- retry_wait 使用带随机抖动的有限指数退避，恢复联网或用户主动重试可提前唤醒；
- rejected_forbidden 不自动复制到个人空间，也不反复发送；
- rejected_version 使目标只读并要求升级/迁移；
- acknowledged 收据至少保留 400 天，以覆盖支持的离线窗口和高风险命令幂等。

### SYNC-034：pull 与游标

- 服务端按单一空间 ServerSequence 严格递增返回变化页；默认每页最多 500 项或 2 MiB；
- 每项包含实体最新服务器版本、变化类型和适用墓碑，不依赖 updatedAt 排序；
- 客户端在本地事务中验证并应用完整页面，之后才推进 SyncCursor；
- 页面重试必须返回兼容结果；重复变化按 serverVersion 忽略；
- 应用远端变化后，重放/重新校验尚未发送的本地 mutation；
- 一个空间的 cursor 不能用于另一个空间或另一个快照 generation。

### SYNC-035：完整快照重建

以下情况停止增量并要求快照：

- cursor 早于服务端保留窗口；
- snapshot generation 改变；
- 本地完整性检查失败；
- 未知变更被新客户端支持后恢复；
- 云备份恢复或服务端修复创建新世代。

客户端先冻结该空间网络写入、保存未确认本地 mutation 和设备加密检查点，在暂存数据库下载、校验快照与附件清单，再重放仍合法的本地 mutation。全部成功后原子切换；失败继续使用原副本并显示 integrity_blocked，不用空库覆盖。

### SYNC-036：运行触发与节流

同步在用户主动刷新、App 启动/前台、领域写入后网络可用、系统后台机会和远程静默信号时尝试。后台机会不保证执行；批量变更、低电量和计费网络遵循平台/用户设置。用户主动创建的小型变更优先，附件可延后。

## 5. 冲突判定与解决

### SYNC-040：三方比较

对可更新实体比较：

- base：本地操作所基于的 serverVersion 快照；
- local：该 mutation 想产生的字段；
- remote：服务器当前版本。

不同字段变化且组合后仍满足领域不变量时自动合并；同一标量字段不同值形成 SyncConflict。自动合并也创建新 serverVersion、ServerSequence 和无内容审计摘要。客户端 updatedAt、到达网络的先后和显示名不决定普通字段胜负。

### SYNC-041：通用优先级

1. 服务端权限撤销与永久删除墓碑不可被用户冲突选择覆盖；
2. sensitivity 和 aiAccess 并发时采用更严格结果；
3. 关系实体的并发增删默认删除优先；
4. 归档可与内容编辑合并；
5. 删除到回收站优先隐藏，但保留冲突内容，恢复时让用户选择；
6. 任何自动结果必须仍通过当前领域规则；否则转为冲突。

### SYNC-042：按对象的默认规则

| 对象或并发变化 | 规则 |
| --- | --- |
| 同一记录的不同普通字段 | 三方自动合并。 |
| 同一普通标量字段 | 保留双方，用户选择或编辑新值。 |
| 备忘长正文双方修改 | P1 不自动文本拼接，显示双方版本。 |
| 归档与普通内容编辑 | 合并内容并保留归档；解除归档后可见。 |
| 回收站删除与内容编辑 | 回收站优先；恢复时解决编辑版本。 |
| 永久删除与任何旧修改 | 墓碑优先，旧 mutation 拒绝。 |
| 分类删除与记录设置该分类 | 分类删除优先，记录 categoryId 置空并提示。 |
| 标签/关联不同关系 | 关系实体分别合并；同一关系增删时删除优先。 |
| 不同清单项目 | 自动合并。 |
| 同一清单项目标题/数量 | 同字段冲突。 |
| 同一项目勾选/取消 | 按服务端接受顺序形成操作历史，当前状态取最后已接受操作；用户仍可再次切换。 |
| 项目删除与编辑/勾选 | 删除优先，编辑保留在冲突详情到用户关闭。 |
| 清单排序 | 稳定 SortKey 合并；同一项目并发移动按服务端接受顺序。 |
| 同一周期实例动作重试 | clientMutationId 幂等返回原结果。 |
| 同一周期实例完成与跳过 | 语义冲突，不自动选；用户基于最新状态处理。 |
| 重复规则并发编辑 | 整个 RecurrenceSegment 冲突，不拼接规则。 |
| 不同库存买入/使用流水 | 不可变流水全部保留，由服务端 ledgerSequence 排序重算。 |
| 合并库存后将为负 | 导致负数的后接受 mutation 拒绝为冲突，不改写数量。 |
| adjust 与其 base 后的新流水 | base 已变即冲突，不把旧目标数量静默重解释。 |
| 不同附件新增 | 合并。 |
| 附件移除与重传/修改元数据 | 移除优先。 |
| 提醒计划时间双方修改 | 冲突；不得静默改变明确提醒。 |
| AuditEvent | 只追加，不编辑、不合并。 |

### SYNC-043：冲突界面与提交

- 展示对象、字段标签、本机值、云端值、两边设备/成员和相对时间；敏感内容先要求应用解锁；
- 不以“最新”暗示设备时钟更正确；
- 用户可以选本机、云端或输入合并值，整组规则必须预览后整体选择；
- 解决命令引用 base/local/remote 版本并生成新 clientMutationId；
- 目标已再次改变时重新加载，不用旧选择覆盖；
- 未解决冲突不阻塞查看，涉及该字段的新编辑先在同一界面解决；
- 目标被永久删除、成员失权或规则已不可用时 conflict 进入 invalidated。

## 6. 删除、回收站与墓碑

### SYNC-050：回收站是普通同步状态

trashedAt、purgeAfter、trashedFrom 和恢复作为领域变化同步。任一设备恢复后产生新 serverVersion；其他设备取消原删除后的本地清理任务并按业务规则重建未来提醒。30 天以服务端确认的删除时刻作为跨设备安全基准，设备离线显示可以使用本地估算但不能提前永久删除云端。

### SYNC-051：永久删除

- purge 请求必须引用当前 serverVersion 并通过高风险确认/权限；
- 服务端在同一事务删除聚合可见内容、创建 Tombstone、分配 ServerSequence 和排队附件擦除；
- 客户端收到墓碑后删除本地聚合、冲突快照、提醒和附件副本；
- 删除失败保留回收站对象，不显示已永久删除；
- 级联子 ID 不可作为新对象重新上传。

### SYNC-052：保留窗口

P1 默认最小墓碑和 mutation 收据保留 400 天。超过窗口未同步的 Device 在下次访问时必须完整快照重建；服务端不得接受其基于过期 generation 的旧写入。账号/家庭删除后的法律和安全最小记录由合规规范控制，但不能用于恢复生活正文。

## 7. 附件同步

### SYNC-060：内容与元数据分离

1. 本地附件先按普通规则加密并计算 ContentHash；
2. 创建元数据 mutation 和 AttachmentTransfer；
3. 服务端授权临时上传会话；
4. 客户端按分块幂等上传，支持断点续传；
5. 服务端验证总大小、哈希、MIME 安全约束和空间权限；
6. 内容 available 后才向其他设备确认可下载引用；
7. 本机领域记录不因网络上传失败消失，显示“已保存在本机，附件待同步”。

### SYNC-061：下载与本地可用性

- pull 到附件元数据后显示占位，不把未验证文件标 available；
- 按用户网络/空间设置下载，用户打开时优先；
- 写入临时密文、完成哈希和认证校验后原子提升；
- missing/corrupt 只影响该附件，记录其余内容可用；
- 没有空间时暂停并说明，不清除其他内容腾空间；
- 缓存清理只移除可重新下载的本地密文，保留元数据和用户明确的离线副本设置。

### SYNC-062：孤儿与删除

未被领域 mutation 引用的已上传临时块在 24 小时后可清理；正在重试且授权仍有效的传输续期。移除附件先传播关系/元数据删除，再按所有合法引用和保留策略擦除服务端内容。内容哈希去重不得让删除一条记录破坏另一条合法引用。

## 8. 提醒与多设备

### SYNC-070：同步业务计划，不同步平台队列

- ReminderPlan、ReminderInstance 的业务状态和适用去重键同步；
- NotificationDelivery 的平台调度 ID、权限和本机尝试不跨设备同步；
- pull 应用时间、完成、归档、删除或敏感变化后写入本机对账任务；
- 每台 Device 按 REM-121 的订阅设置产生独立投递；
- 同一账号多个设备可能在同步到达前各展示一次，不能承诺跨设备恰好一次。

### SYNC-071：通知动作

通知动作先执行本地幂等领域命令和 outbox。服务器若发现另一设备已处理同一逻辑实例，返回既有结果或语义冲突；客户端更新本地状态并清理过时通知，不追加第二条完成/库存流水。

## 9. 云备份

### SYNC-080：P1 默认保护

P1 云备份通过传输加密和服务端存储加密保护，并受账号授权；不承诺端到端加密或用户口令不可恢复性，OQ-006 关闭前不使用相关营销表述。CloudBackup 的内容与同步在线状态隔离，列出创建时间、设备、格式版本、大小、范围和状态。

### SYNC-081：创建与保留

- 服务端从一个已确认的空间 ServerSequence 创建一致快照，不接受设备拼接的半同步文件；
- 创建期间后续同步可以继续，备份固定在其基线 sequence；
- 失败副本不进入 available；
- 用户可手动创建、验证和删除；自动频率/数量属于未来商业与存储策略，在决定前不默认承诺；
- 删除备份与删除同步数据是两个确认动作。

### SYNC-082：恢复世代

恢复同步个人空间：

1. 展示备份时间、范围、将回退/移除的当前变化和所有设备影响；
2. 要求近期重新认证和输入确认；
3. 暂停该空间新服务端 mutation；
4. 创建当前状态内部回滚检查点；
5. 在暂存空间验证备份和迁移；
6. 原子替换权威状态并创建新 snapshot generation；
7. 所有设备进入 snapshot_required，未上传操作单独列出供重放或导出；
8. 失败则恢复原 generation 并解除暂停。

同步引擎不得把恢复后的旧值逐条当成“较新编辑”覆盖当前数据。

### SYNC-083：本地备份进入已绑定数据集

从 `.lifebook` 恢复前暂停同步并检查备份 provenance：

- 同一 Account：可以选择替换云端（走恢复世代）、通过通用导入合并，或恢复为仅本机副本；
- 其他 Account：禁止上传，只能登录来源账号、保持仅本机，或导出后作为新对象导入；
- 无来源账号：预览后由当前账号明确认领；
- 取消/失败恢复原绑定和原数据库，不消费远端变化。

## 10. 设备管理、退出与账号删除

### SYNC-090：设备列表与撤销

账号设置显示 Device 名称、平台、首次/最近活动和当前设备标记，不显示硬件指纹或精确位置。撤销：

- 需要近期重新认证；
- 服务端原子撤销该 Device 的所有会话、上传授权和推送令牌；
- 后续请求返回 device_revoked；
- 不删除云端数据或影响其他设备；
- 不能承诺远程擦除已经离线解密、导出、截图或备份的数据；
- 被撤销设备联网后停止同步、清理服务令牌和家庭本地缓存，个人副本进入需要登录/保留/清除选择，不在后台静默永久删除。

### SYNC-091：退出登录

退出前显示未同步数量并提供：

| 选择 | 结果 |
| --- | --- |
| 同步完成后保留本地副本 | 上传成功后解除绑定；创建新的本地 owner，保留 provenanceAccountId，移除家庭缓存。 |
| 立即保留本地副本 | 未上传变化只留本机，明确说明不会出现在其他设备；清空 outbox/server 元数据，保留内容和来源标记。 |
| 清除本地副本 | 撤销会话后按 DATA-090 清除个人和家庭副本；不删除云端账号。 |
| 取消 | 不改变任何状态。 |

保留副本时既有作者和审计 ID 不改写；新建本地 LocalActor 成为个人空间 owner。以后登录其他 Account 时触发 SYNC-023，不能自动上传。

若离线无法联系服务端，客户端可以销毁本地令牌并退出；短期服务端会话在到期前可能仍显示 active，界面说明可从另一设备撤销。本机清除不等待无限网络重试。

### SYNC-092：账号删除

1. 展示个人空间、云备份、设备、家庭角色、待同步、导出机会，以及“把个人空间保留为仅本机副本”或“同时清除此设备副本”的选择；
2. 家庭 owner 必须先转移所有权或进入家庭删除流程；
3. 近期重新认证并双重确认；
4. 默认进入 7 天 deletion_pending，显示精确永久删除日期并允许取消；
5. 期间撤销普通设备会话，只保留受限删除会话；
6. 到期删除个人同步内容、云备份、认证身份和会话，传播账号/空间墓碑；
7. 依法或安全必须保留的最小收据不得含生活正文，并按法律规范期限处理；
8. 选择保留个人空间时按 SYNC-091 解除绑定，以新 LocalActor 继续使用个人内容并保留 provenance；选择清除时建立空默认个人空间。两种路径都不得复制家庭内容。

运营主体和地区确定后，法律文档可以要求不同等待/保留，但必须同步形成产品决策和迁移说明，不能静默改变已展示日期。

## 11. 用户可见状态和诊断

### SYNC-100：状态语言

| 内部状态 | 用户文案原则 |
| --- | --- |
| local committed, pending | 已保存在本机 · 等待同步 |
| syncing | 正在同步，不显示伪精确百分比除非总量已知 |
| acknowledged | 已同步 |
| offline_queued | 当前离线 · 会在联网后同步 |
| auth_required | 需要重新登录 · 本机数据仍在 |
| conflict | 有一处需要你选择 |
| upgrade_required | 需要更新 App 才能继续同步；保持只读保护 |
| integrity_blocked | 同步已暂停，数据仍保存在本机；提供诊断/导出 |

不得把“请求已发送”显示为“所有设备已经同步”。

### SYNC-101：设置页

至少展示：账号标识、绑定空间、同步开关、最后成功同步、待上传/下载/附件/冲突数量、当前错误、网络限制、设备列表、云备份、导出、退出和账号删除。诊断详情只含不透明 ID、版本、数量和受控错误码。

### SYNC-102：故障隔离与恢复

- 临时网络/5xx：保留队列并退避；
- 认证过期：暂停空间，重新登录后从原 cursor 继续；
- 权限拒绝：停止目标 mutation 并解释，不自动换空间；
- 配额/存储不足：优先同步小型元数据，附件暂停并提供管理入口；
- Schema 未知：保护性只读，允许导出，不尝试删字段；
- 本地完整性失败：停止相关写入，创建诊断副本并走 DATA-121；
- 服务端错误不得清空本地数据或自动退出账号。

## 12. 安全、隐私和运行数据

### SYNC-110：内容保护

- 全部网络使用 TLS；服务端业务存储和对象存储静态加密；
- Account、Space 和附件授权在服务端执行，不能只依赖不可猜 ID；
- access/refresh token、验证码、邮件供应商密钥和对象存储签名 URL 不进普通日志；
- 同步错误追踪不记录标题、正文、清单项目、物品名、位置、附件名或精确生活值；
- 临时冲突快照与源记录同级加密，解决后最迟 30 天清理；
- 支持人员不能直接浏览生活内容；需用户主动提交且按支持规范处理。

### SYNC-111：无内容运行指标

允许按粗粒度记录：请求 ID、Account/Space 不可逆内部关联、客户端/协议版本、mutation/实体类别、批次数量和字节分桶、结果码、重试、延迟、cursor 落后量、附件状态和冲突字段类别。禁止记录字段值和原始 payload。

### SYNC-112：设备时钟异常

设备时间只用于本机显示和用户声明业务时刻。服务端收据时间、ServerVersion 和 ServerSequence 决定同步顺序；检测到设备时钟明显偏差时提示用户，但不回写历史业务时间或使用 LWW 覆盖。

## 13. 实施与验收测试矩阵

### SYNC-120：身份和误上传

至少覆盖：

- 本地/云端四种组合和每个选择；
- 登录、取消、验证码重复、会话轮换、令牌撤销；
- 认领中断的每个 lastCompletedStep；
- 完整备份恢复出的 LocalActor 映射；
- provenance 属于另一个 Account 时所有路径均不上传；
- 退出保留后登录相同/不同账号；
- 账号删除等待期取消和到期。

### SYNC-121：传输和顺序

至少用两台 iOS、两台 Android 和跨平台组合覆盖：离线编辑、乱序、重复 push、响应丢失、分页 pull、进程终止、退避、cursor 损坏、快照重建、服务升级与旧客户端。每个 clientMutationId 在任意重试序列下最多产生一次业务结果。

### SYNC-122：领域冲突

对 SYNC-042 每一行提供自动化三方 fixture，验证最终领域不变量、冲突 UI 输入和新 serverVersion。库存并发至少覆盖余额恰为 0、会为负、adjust 基准变化；重复规则覆盖 DST 与系列切分；清单覆盖项目状态与排序。

### SYNC-123：删除和长期离线

覆盖 trashed/restore/purge 在不同设备交错、墓碑重复、附件擦除、离线 399 天和 401 天设备、过期 generation 写入、账号删除和家庭成员失权。任何旧副本不得复活永久删除 ID。

### SYNC-124：附件与空间故障

覆盖分块重复/乱序、网络切换、哈希错误、密文损坏、临时上传过期、引用删除、存储不足和只下载占位。失败不得产生对其他设备可见的 available 空附件。

### SYNC-125：备份与提醒

覆盖云备份创建中继续编辑、恢复 generation 切换、恢复失败回滚、本地 `.lifebook` 的三种 provenance、未上传 mutation 重放，以及远程完成后各设备取消未来提醒。平台队列 ID 不得跨设备复制。
