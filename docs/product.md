# 产品说明

## 1. 定位

生活有谱是面向个人与家庭的生活记录和提醒工具。它把重复日常、可复用清单、备忘、重要日期和家庭物品放在一个地方，核心价值是**减少记忆负担**：该做的事会出现，该准备的东西有清单，重要的日子不会错过，家里有什么心中有数。

产品气质：温和（不用焦虑催促）、清楚（容易理解和查找）、可靠（该出现时出现）、贴近日常（从真实小事出发）。

### 非目标

- 不做企业项目管理、团队协作或绩效工具；
- 不做医疗级告警或紧急响应；
- 不做财务记账或企业库存；
- 不做公开社交社区；
- 不允许 AI 未经用户确认直接创建、修改或删除记录（AI 属于后续阶段）。

## 2. 多端分工

| 端                    | 主要场景                               | 首期能力                                               |
| --------------------- | -------------------------------------- | ------------------------------------------------------ |
| 手机（iOS / Android） | 随手记录、查看今天、接收提醒、勾选完成 | 全部记录的增删改查、今天、搜索、本地通知               |
| Web                   | 在电脑上批量整理、查看全貌、编辑长内容 | 全部记录的增删改查、今天、搜索、批量操作；不发系统通知 |

两端读写同一份服务端数据，登录同一账号后看到的内容一致。

## 3. 五类记录

所有记录共有：标题、说明（备忘的正文）、分类（最多一个）、标签（多个）、置顶、归档、删除到回收站、创建和修改时间。记录类型创建后不可更改。

| 类型     | 说明                                            | 关键规则                                                                                                                                                                                                           |
| -------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 重复日常 | 每天、每周、每月、每年或每隔 N 天/周/月要做的事 | 每次发生是独立的“周期实例”，状态为待完成、已完成、已跳过；过了计划时间仍未处理即“逾期”（派生状态，不存储）。完成或跳过可撤销。修改规则只影响今天以后，已完成和已跳过的历史不变。                                   |
| 清单     | 旅行、搬家、采购等场景的勾选清单，可从模板创建  | 模板和实例互相独立：从模板创建后修改实例不影响模板，反之亦然。全部有效项目勾选即完成，新增或取消勾选会重新打开，空清单不算完成。                                                                                   |
| 备忘     | 需要长期查找、偶尔在某个时间再看到的信息        | 没有完成状态；可设一个或多个提醒，提醒处理后正文保留。标题和正文不能同时为空。                                                                                                                                     |
| 重要日期 | 生日、纪念日、到期日等                          | 事件种类、仅一次/每年、日期、可选起始年份分开保存。有起始年份时可显示年龄或第 N 周年。没有完成或逾期状态。首期只支持公历。                                                                                         |
| 家庭物品 | 家里东西的数量与存放位置                        | 数量变化（期初、买入、使用、调整、报废、丢失）形成不可修改的库存流水，改错用新的“调整”流水。数量不能为负。当前数量 `<=` 最低库存即“低库存”，一次连续低库存只提醒一次。可加入采购清单，同一物品在同一清单里不重复。 |

## 4. 今天

“今天”回答三个问题：今天有什么要做？最近有什么不能忘？家里有什么要补？

- 逾期的周期实例（同一事项多次逾期只显示一张卡片，注明还有几次未处理）；
- 今天的周期实例、今天截止的清单、今天的备忘提醒；
- 今天及未来 7 天内的重要日期（“今天是妈妈的生日”“还有 7 天”）；
- 低库存物品。

每类卡片只显示适合它的动作：周期实例可以完成或跳过，清单可以打开或勾选，备忘、重要日期和低库存没有“完成”。

### 日历

日历按**日 / 周 / 月**查看哪些日子有事，回答“那天有什么安排”：

- 标出今天和现在的时刻；有内容的日期在格子里显示事项（Web 宽屏）或彩色圆点（手机和窄屏），已处理的变淡，逾期的标红。
- 内容和“今天”一致：周期实例（按改期后的日期）、重要日期、清单截止和备忘提醒；低库存没有日期，不在日历里。
- 点一天在旁边或下方列出当天的事项，周期实例可以直接完成、跳过或撤销；点事项打开详情。今天的列表里标出“现在”。
- 一周从周一开始。过去未处理的实例显示为逾期，不受“今天”里 30 天回看的限制。

## 5. 提醒

- 重复日常、清单、备忘和重要日期可以设置提醒；重要日期可设多个提前提醒（如提前 7 天、1 天和当天）。
- 每个提醒默认只发一次，不连续催促。
- 手机端在系统通知里提供“完成”“稍后提醒”等适用动作；“稍后提醒”只推迟这一次通知，不改变记录本身的时间。
- 没有通知权限时，记录照常保存，“今天”照常显示，并提示如何开启权限。
- Web 端首期不发系统通知，只在“今天”中展示。

## 6. 页面结构

**手机**：底部五个标签“今天 / 日历 / 生活簿 / 家中 / 我的”，加一个全局“+”按钮，用来新建五类记录。

**Web**：左侧导航“今天 / 日历 / 生活簿 / 家中 / 清单模板 / 设置”；生活簿采用“列表 + 详情”双栏，支持多选后批量归档、删除、改分类和加标签。

**通用**：用户名 + 密码登录（账号由管理员用脚本创建，没有注册入口）、记录详情和编辑、搜索、分类与标签管理、回收站、账号设置（时区、默认提醒时间、修改密码、退出登录）。

## 7. 分期

| 阶段      | 内容                                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------------------- |
| MVP       | 账号登录；重复日常、重要日期、备忘；今天；生活簿列表、筛选、搜索；手机本地提醒。                                |
| V1        | 清单与模板；家庭物品与库存；分类和标签管理；回收站（30 天）；数据导出（JSON）。                                 |
| V2 及以后 | 部署上线与内测；一句话 AI 创建；图片附件；家庭共享空间；服务端推送与 Web 通知；农历日期；敏感内容保护；多语言。 |

各阶段的具体任务见 [开发计划](plan.md)。
