# 归档资料

这里是 2026-07 至 2026-08 期间的规划与工程资料，**已停止维护，只作参考**。归档原因和替代关系见 [决策记录](../docs/decisions.md)。

| 目录 | 内容 |
| --- | --- |
| `docs/` | 旧产品、体验、领域、治理文档和 13 份 ADR。产品细节（如业务规则、页面规格、文案）仍有参考价值。 |
| `specs/` | 标量、安全、备份、测试的机器合同与 fixtures（端侧加密方案，已不适用）。 |
| `evidence/` | Android 原生能力验证报告（SQLCipher、通知、Keystore 等均通过）。 |
| `tools/oracles/` | 上述合同的 oracle 校验脚本，依赖已移除，不能直接运行。 |

目录结构与原位置一致，因此文档之间的相对链接仍然有效。指向已删除代码（如 `apps/android-capability-spike`）的链接可以在 Git 历史中找到。
