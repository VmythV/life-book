# 生活有谱可访问性规范

> 项目代号：`life-book` · 版本：v1.0 · 更新日期：2026-07-26 · 状态：实施基线
>
> 权威范围：移动端与 Web 的可访问语义、视觉可辨性、动态字体、输入方式、焦点、错误、隐私、测试与发布门槛
>
> 不负责：最终视觉 token、最终中文文案、业务状态、页面路由、原生组件具体代码和法律上的合规认证
>
> 依赖文档：[质量属性](quality-attributes.md)、[页面规格](screen-specifications.md)、[用户流程](user-flows.md)、[内容语言](content-design.md)、[信息架构](information-architecture.md)、[提醒规范](reminders-and-notifications.md)

本规范细化 QR-080～QR-082。项目以适用的 WCAG 2.2 AA 为统一产品基线，并遵循 iOS、Android 的原生辅助功能语义；这是一项实现和测试目标，不等于在第三方审计前作出法律合规声明。

## 1. 原则与适用范围

### A11Y-001：同一任务、同一结果

使用 VoiceOver、TalkBack、Switch Control、Voice Access、外接键盘、放大字体、减少动态效果或单指替代操作时，用户必须能完成与默认触控相同的核心任务。辅助路径不得自动降级数据保护、跳过影响预览或改用不同业务命令。

### A11Y-002：阶段不能降低基线

- P0：全部本地页面、系统权限前置说明、备份/恢复/导出和应用锁达到本规范；
- P1：账号、同步、导入、关联、语音和多草稿沿用同一门槛；
- P2：家庭、公共模板、识别与 Web 沿用同一门槛；
- 新页面在进入信息架构时必须同时获得语义、焦点、动态字体和替代输入验收项。

### A11Y-003：隐私输出一致

视觉遮罩、读屏名称、提示、系统通知、可访问性树、自动化标识和日志必须使用同一敏感边界。未解锁时不得让读屏读出标题、家庭名、数量、日期、附件类型、内容长度或被视觉隐藏的后台页面。

## 2. 语义结构

### A11Y-010：名称、角色、值和状态

每个可操作元素必须提供：

- 唯一且能脱离视觉位置理解的可访问名称；
- 与行为一致的原生 role；
- 适用的 checked、selected、expanded、disabled、busy、invalid、current 等状态；
- 值发生变化时由控件语义更新，不把全部信息塞进一段 label；
- 可见文字是名称的一部分，语音控制说出可见标签即可命中。

图标按钮不能只读“按钮”或文件名；例如使用“关闭创建”“更多清单操作”“移除附件”。重复列表行的动作名称包含安全对象上下文；敏感遮罩时改用“打开敏感记录”等通用名称。

### A11Y-011：标题、分组与层级

- 每页有且只有一个可识别的主标题；分区使用原生 heading 语义且层级连续；
- 表单 label 与输入建立程序化关系，帮助、错误和单位分别关联；
- 卡片内标题、原因、状态和动作形成一个可理解分组，不能把整屏合成一个巨大元素；
- 装饰图、分隔线和重复背景从可访问性树移除；有信息的图片提供目的性替代文本；
- 列表声明项目数量与当前位置的能力由平台提供时不覆盖原生行为。

### A11Y-012：状态通知

以下变化使用不会抢走焦点的状态公告：保存成功/失败、筛选结果数量、同步状态、附件完成、复制完成、库存意图进入待同步、表单错误摘要。危险确认、会话失效或页面被权限移除需要显式焦点移动。

公告必须：

- 简短说明结果和数据是否安全；
- 合并高频更新，进度最多在有意义阶段公告，不能逐百分比轰炸；
- 不重复读出当前聚焦控件已经表达的内容；
- 不包含被敏感模式隐藏的字段值。

## 3. 读屏与焦点

### A11Y-020：阅读顺序

读屏顺序与视觉和业务顺序一致：页面标题 → 状态/错误摘要 → 主体字段/内容 → 次要信息 → 主要动作。视觉绝对定位、双栏和平板布局不能改变逻辑顺序。

列表—详情双栏中，打开详情先聚焦详情标题；关闭详情回到原行。虚拟列表卸载项目时保存稳定实体 ID，而不是像素位置或数组下标。

### A11Y-021：进入、返回和恢复焦点

| 场景 | 焦点结果 |
| --- | --- |
| 普通页面 push | 新页面标题或最有意义的首个元素。 |
| modal/bottom sheet 打开 | 弹层标题；焦点限制在弹层。 |
| modal 取消/完成 | 返回触发控件；控件已消失则返回最近稳定容器。 |
| 字段提交失败 | 先公告错误摘要，再允许跳到第一个错误字段。 |
| 删除成功 | 回来源列表标题或删除位置附近的下一项，不聚焦已删对象。 |
| 列表刷新 | 保持当前实体；实体消失时公告原因并移动到列表标题。 |
| 解锁成功 | 重新查询后进入安全目标标题，不恢复被遮罩内容的旧子焦点。 |
| 深链接失效 | 聚焦失效状态标题和合法返回动作。 |

### A11Y-022：焦点可见与无遮挡

- 键盘、Switch Control 和 Web 焦点始终有清晰指示，不只改变颜色；
- 指示器与相邻未聚焦状态至少达到 3:1，且不得被粘性底栏、键盘、toast 或安全区遮住；
- 页面自动滚动只为把新焦点完整带入可视区域，不造成循环跳动；
- 焦点不能进入关闭弹层、遮罩后的敏感树、不可见标签页或卸载中的内容。

## 4. 字体、重排与方向

### A11Y-030：动态字体

- 使用系统可缩放文本样式，不把正文或按钮文字转成图片；
- iOS 覆盖全部 Dynamic Type 档位，Android 至少覆盖系统 200% 字体缩放；
- 在最大测试档位，创建五类记录、处理提醒、库存操作、备份恢复、删除确认、登录和家庭邀请不得丢失字段或主动作；
- 空间不足时从横向并排改为纵向、换行或可进入的详情，不缩小字体抵消用户设置；
- 允许普通摘要截断，但同屏或一次操作内提供完整安全文本；危险动作、状态、错误和数值单位不得只以省略号存在。

### A11Y-031：缩放与重排

P2 Web 在 320 CSS px 等价宽度及 200% 文本缩放下保持单向滚动和完整功能；数据表或必要二维内容可以局部双向滚动，但页级导航、保存和错误不能被锁在横向滚动外。

移动横屏、分屏和平板不能要求特定方向才能完成任务；相机采集等确有硬件方向限制的能力必须提供文件选择或手动输入替代。

### A11Y-032：数字和混合文本

日期、数量、单位、版本、邮箱、ID 和中英文混排使用可正确朗读的本地化文本；不依赖字符画表达 before→after。库存变化的可访问值读作“原数量…，变化…，新数量…，状态待同步/已确认”。诊断 ID 支持逐字符复制，默认不强制读完整长串。

## 5. 颜色、对比与视觉状态

### A11Y-040：对比度

- 普通文字与背景至少 4.5:1；大号文字至少 3:1；
- 获得信息所必需的控件边界、图标、焦点和状态图形与相邻颜色至少 3:1；
- disabled 控件可以不按上述数值，但仍须能与可用状态区分，且关键不可用原因必须由文字提供；
- 渐变、图片和模糊背景上的文字按最差有效区域校验；无法保证时增加实色表面；
- light/dark、高对比度、系统着色和敏感遮罩分别测量，不能只验证设计稿中的一个主题。

### A11Y-041：不只依赖颜色

记录类型、低库存、完成/跳过、错误/警告、同步/离线、空间、敏感、选中和审核状态必须同时使用文字、图标、形状或结构中的至少一种非颜色线索。图例不能要求用户记住颜色后回到内容判断。

### A11Y-042：图片和附件

- 用户图片的默认替代文本描述用途，例如“家庭物品主图”，不尝试猜测敏感内容；
- 用户明确填写的图片说明可作为替代文本，但敏感时仍受锁和通知边界；
- OCR/识别结果作为可编辑文字呈现，不能要求用户从图片中自行核对唯一信息；
- 附件 missing/corrupt/processing 由文字状态表达；装饰缩略图从树中隐藏。

## 6. 触控、键盘与替代输入

### A11Y-050：目标大小

- iOS 交互热区至少 44×44 pt；Android 至少 48×48 dp；视觉图标可以更小但热区不能与相邻动作重叠；
- P2 Web 的常规产品控件目标优先至少 44×44 CSS px，并至少满足 WCAG 2.2 AA Target Size (Minimum) 的适用要求；
- 行内文字链接、系统原生控件或技术允许的例外仍要提供足够间距和等价大目标；
- 整行可点时，行内独立按钮必须有各自语义和不重叠命中区域。

### A11Y-051：手势替代

- 滑动删除、长按菜单、捏合、路径手势、摇动和拖放都必须有单指点击替代；
- 清单/模板拖动排序同时提供“上移/下移/移到分组”按钮，并公告新位置；
- 滑动动作在抬起前可取消，破坏性结果仍遵循撤销/确认规则；
- 系统返回手势与可见返回/取消语义一致。

### A11Y-052：键盘和开关控制

- P2 Web 所有功能可用键盘完成且无焦点陷阱；Tab 顺序遵循结构，Enter/Space 行为符合控件角色，Escape 只关闭最上层可取消界面；
- 移动端外接键盘提供标准导航和激活动作，不要求自定义快捷键；
- 单字符快捷键若未来提供，必须可关闭、重新映射或仅在特定控件聚焦时生效；
- Switch Control 扫描组不能过大，重复卡片动作按卡片分组。

### A11Y-053：语音和运动

可见按钮文字必须包含在可访问名称中，保证 Voice Control/Voice Access 可按标签激活。任何摇动、倾斜或相机动作都有按钮/文件选择/手动输入等替代；语音创建是可选输入，不是唯一创建途径。

## 7. 表单、错误和高风险任务

### A11Y-060：输入

- label 持续可见，不用 placeholder 代替；placeholder 只给格式示例；
- 使用合适键盘、输入 purpose 和自动填充，但不阻止粘贴、密码管理器或验证码自动填充；
- 数量输入把单位作为关联说明，错误说明允许值和当前保留状态；
- 日期/重复选择器提供文本摘要与可键盘/读屏操作的控件，不要求理解日历格颜色；
- 条件字段出现/消失时公告变化并把焦点保持在触发控件，除非用户明确进入新字段。

### A11Y-061：错误和状态

错误通过文字、invalid 状态和关联说明表达，不只改变边框。提交后顶部摘要列错误数量并链接到字段；修复一个错误不清其他输入。网络、权限和完整性错误必须说明“数据是否已保存”。

### A11Y-062：防误操作

覆盖、永久删除、清除本机、账号/家庭删除、放宽敏感保护、跨空间移动和恢复备份必须：

1. 在提交前读出对象、范围、是否可恢复和生效时间；
2. 不用颜色或位置区分“取消”和危险动作；
3. 输入确认词时允许粘贴且提供可读要求，不能用记忆谜题或纯认知测试；
4. 提交后公告结果与下一步；失败保留上下文；
5. 重新认证支持系统凭据、密码管理器和平台辅助能力。

### A11Y-063：时间限制

普通表单没有不可延长的业务倒计时。验证码、邀请和所有权转移等安全期限必须显示绝对时间与剩余说明；会话将过期时有提前提示和重新认证路径，不因读屏速度较慢静默丢失输入。

## 8. 动效、声音与触觉

### A11Y-070：减少动态效果

- 遵循系统 Reduce Motion/移除动画设置；页面切换改为淡入或即时状态，不保留视差、弹簧、自动缩放和大范围位移动画；
- 骨架和进度不快速闪烁；任何内容每秒不得闪烁三次以上；
- 自动轮播默认不使用；示例轮换可暂停且读屏聚焦时不改变；
- 关闭动效不应改变任务时序、保存结果或状态公告。

### A11Y-071：声音和触觉不是唯一反馈

成功、失败、低库存、拖动位置和扫码结果始终有视觉文字与语义状态；声音/振动只作补充并尊重系统和用户设置。产品不依赖特定音高、左右声道或触觉模式传递唯一含义。

## 9. 关键页面专项规则

### A11Y-080：今天与列表

- 分组标题可用 heading 导航；卡片名称包含类型、状态和安全标题，不重复读整段正文；
- 快捷动作不是隐藏手势的唯一入口；动作后保留或合理恢复列表焦点；
- 分页/虚拟化不改变阅读顺序，新增结果不把用户拉回顶部；
- 空状态与加载状态使用不同语义，不能把加载中读成“没有记录”。

### A11Y-081：库存和清单

- 数量、单位、确认/预估、阈值和待同步状态分别可读；颜色箭头不是唯一变化说明；
- 清单项目使用可切换语义，读出标题、数量、完成状态和所在分组；
- 批量完成先读影响数量；项目排序有非拖动替代；
- rejected 库存意图聚焦错误摘要，原输入仍可查阅但重新提交创建新意图。

### A11Y-082：智能功能

- inferred/default/用户确认来源用文字表达；不能只靠颜色、图标或置信度；
- 生成中可取消，取消后公告“没有保存”；
- SCR-523 逐条读出本次选中的记录/字段和被排除原因，敏感禁止项不泄露标题；
- 模型错误不朗读供应商原文或内部规则；手动路径始终可达。

### A11Y-083：系统通知和锁屏

通知动作名称与 App 内名称一致且短；敏感通知的可访问内容不能比视觉内容更详细。动作需解锁时先说明“打开生活有谱后继续”，认证取消不执行业务动作。声音或横幅被系统抑制不改变 App 内状态。

### A11Y-084：家庭与空间

当前空间以文字持续显示；切换空间后公告新空间和角色，不能只变颜色。成员角色、subscription active/paused/cancelled、mode=off、移动/复制差异都有可读文本。失权时先清理可访问性树再显示无内容状态。

## 10. 组件验收契约

每个共享组件在目录中必须记录：

| 项目 | 必填内容 |
| --- | --- |
| 语义 | role、name 来源、value/state、heading/group 行为。 |
| 焦点 | 默认进入、退出恢复、disabled/hidden 行为。 |
| 尺寸 | iOS/Android/Web 命中区域与间距。 |
| 字体 | 最大档位换行、截断和纵向重排。 |
| 视觉 | light/dark/高对比度下文字、图标、边界和焦点对比。 |
| 输入 | 触控、读屏、键盘、Switch/Voice 及手势替代。 |
| 状态 | loading/empty/error/offline/locked/sensitive。 |
| 自动化 | 稳定 testID 与语义查询，不使用最终中文作为唯一定位。 |

未经上述契约的自定义开关、选择器、日期控件、拖动组件和 modal 不得进入产品页面。

## 11. 测试与发布门槛

### A11Y-100：自动化检查

持续集成至少运行：

- 可访问名称/role/state、重复 ID 和 label 关联静态检查；
- light/dark 关键 token 对比度测试；
- 最大字体下关键页面截图/布局断言；
- 键盘焦点顺序和 modal 焦点限制测试（Web）；
- 关键组件使用平台可访问性测试框架扫描；
- 敏感/锁定状态的可访问性树快照，确保没有隐藏内容。

自动化不能替代人工读屏和真机测试。

### A11Y-101：人工矩阵

每个发布候选至少覆盖：

| 平台 | 必测组合 |
| --- | --- |
| iOS | VoiceOver；最大 Dynamic Type；Bold Text/Increase Contrast；Reduce Motion；Switch Control 至少一次关键流程。 |
| Android | TalkBack；200% 字体；高对比度/颜色校正适用状态；Remove animations；Switch Access 或 Voice Access 至少一次关键流程。 |
| P2 Web | 键盘-only；主流屏幕阅读器/浏览器组合；200% 文本缩放与窄视口；高对比度/forced colors。 |

真机关键任务：首次启动、五类手动创建、智能转手动、周期完成/跳过、清单勾选/排序、库存变化/拒绝、搜索、提醒修复、备份/恢复预览、删除/恢复、应用锁。对应阶段另测登录同步、导入关联、家庭邀请/移动/退出和公共模板。

### A11Y-102：缺陷分级

| 级别 | 示例 | 发布处理 |
| --- | --- | --- |
| blocker | 无法完成创建/保存/恢复/取消；敏感内容从读屏泄露；焦点陷阱；危险操作误触。 | 禁止发布。 |
| critical | 核心字段无 label；最大字体遮住主动作；错误无法定位；移动/复制无法区分。 | 禁止对应阶段发布。 |
| major | 次要状态不公告、局部顺序不佳、非核心图缺替代文本。 | 有 owner 与修复版本；不得长期滚动遗留。 |
| minor | 不影响理解/完成的一致性问题。 | 进入普通修复队列。 |

### A11Y-103：验收证据

每个 `SCR-*` 的验收记录包含测试版本/设备/系统、辅助能力、字体/主题、步骤、结果和缺陷链接，不记录生活正文。新组件、导航重构、认证、通知、系统 SDK 或 UI 框架升级后重跑受影响矩阵。
