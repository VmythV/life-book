# 生活有谱页面规格

> 项目代号：`life-book` · 版本：v1.1 · 更新日期：2026-07-26 · 状态：体验实现基线
>
> 权威范围：各 `SCR-*` 页面的内容顺序、输入与操作、页面状态、导航响应、手机/平板适配和阶段扩展
>
> 不负责：业务算法、领域字段定义、最终文案、颜色/字体数值、API/数据库字段和阶段归属
>
> 依赖文档：[信息架构](information-architecture.md)、[用户流程](user-flows.md)、[领域模型](domain-model.md)、[业务规则](business-rules.md)、[智能创建契约](ai-creation-contract.md)、[数据生命周期](data-lifecycle.md)、[账号与同步](account-and-sync.md)、[家庭共享](family-sharing.md)、[质量属性](quality-attributes.md)

本文覆盖信息架构当前全部页面。P0 页面达到逐字段实现粒度；P1/P2 页面锁定职责、关键状态和高风险确认，详细视觉仍复用同一设计系统。

## 1. 页面通用契约

### 1.1 页面框架

所有页面从上到下使用：

1. 安全区域；
2. 导航栏：返回/关闭、短标题、最多两个高频动作、更多菜单；
3. 可滚动主体；
4. 可选粘性摘要或主要动作区；
5. 键盘/系统底部安全区。

手机以单列为主；平板宽度足够时，列表—详情可以双栏，但路由、焦点、返回和深链接必须与单列等价。不得只在悬停中暴露必要动作。

### 1.2 路由输入与守卫

- 路由只接受不透明实体 ID、页面模式和无内容来源标记；
- 页面加载后再从 Repository 读取当前实体，不把整个记录放进路由参数；
- 敏感内容先通过 SCR-002 解锁，或完成当前页面要求的重新认证，再查询和渲染；
- P1/P2 先验证 SpaceMembership；失权进入无内容状态并清理栈中受保护页面；
- 未知类型/版本显示升级保护，不落入默认详情；
- 删除/归档/冲突后的旧路由展示当前状态和合法下一步。

### 1.3 标准状态槽

| 状态 | 页面要求 |
| --- | --- |
| initializing | 300ms 内不闪占位；超出显示与结构一致的骨架。 |
| empty | 解释筛选/空间为何为空，提供真实主操作。 |
| partial | 可用内容照常展示；损坏附件/索引单独标记。 |
| offline | 本地功能不盖全屏；网络动作旁显示状态。 |
| permission_missing | 局部说明、修复入口和不依赖权限的替代。 |
| retryable_error | 保留输入/上下文，重试按钮可达。 |
| blocked_error | 停止写入，显示诊断 ID、恢复/帮助；仅当安全只读检查通过时提供导出。 |
| saving | 主按钮禁用并显示进行中；返回需确认；防重复提交。 |
| locked | 不先渲染内容；认证成功重新查询。 |
| stale/conflict | 显示刷新或冲突处理，不静默覆盖。 |

### 1.4 表单顺序和错误

- 先放用户识别对象所需字段，再放业务时间/数量，再放整理与隐私；
- 必填使用文字和语义标注，不只用颜色或星号；
- 首次失焦可以局部校验，提交时完整校验；
- 错误摘要聚焦第一个错误，并在字段旁显示具体修复；
- 键盘“下一项”遵循视觉顺序，最后一项不直接绕过确认提交；
- 未保存返回使用 FLOW-002；保存成功不保留可重复提交的旧页面。

### 1.5 主要动作

- 一个页面最多一个视觉主动作；危险操作不与普通保存并排同权重；
- 主动作标签使用结果，如“创建清单”“保存修改”“移到回收站”，不用模糊“确定”；
- 删除、覆盖、清除、账号/家庭删除显示对象、范围、可恢复性和发生时间；
- 异步副作用不阻止已经成功的领域操作，但必须展示局部失败和修复入口。

## 2. 启动和主框架

### SCR-001：启动与数据准备

| 区域 | 规格 |
| --- | --- |
| 正常快路径 | 只保留品牌级静态背景/安全遮罩，不播放不可跳过营销动画。 |
| 迁移 | 显示“正在安全更新数据”、当前阶段和可取消性；未知总量不显示伪百分比。 |
| 恢复检查 | 显示正在验证/回滚，不渲染备份内容。 |
| 阻断错误 | 简短原因、诊断 ID、重试、恢复备份/帮助；只有 RecoveryExporter 确认密钥可用且解密成功、数据库可安全只读打开、Schema 有兼容读取器、范围完整性检查通过时才启用“只读导出”，否则隐藏/禁用并说明无内容原因；绝不提供“继续写入”。 |

App 进入后台立即使用无内容遮罩；初始化重入必须幂等。

### SCR-002：应用锁

- 显示产品名、通用“生活内容已锁定”、主动作“解锁”；
- 可以展示当前认证方式，不展示最近记录或通知来源；
- 生物识别失败提供系统允许的设备凭据重试；
- 达到系统限次后说明等待/设备设置；
- 唯一数据无法解锁时提供备份恢复、清除本机和帮助，危险入口二次确认；
- 深链接目标在解锁前不显示标题。

### SCR-003：主框架

- 底部固定“今天 / 生活簿 / 家中 / 我的”，全局加号独立且有可读标签；
- 每个标签保留栈、筛选和合理滚动；再次点根标签回顶部；
- 小屏加号不能遮住最后一项，列表保留底部 inset；
- P0 不显示账号、空间和同步空入口；P1/P2 按登录/成员状态增加而不改变四标签语义；
- 深链接完成后返回到其来源标签的当前栈，而非构造重复根页。

## 3. 今天

### SCR-010：今天

从上到下：

1. 当地日期、简短问候和无内容的设置/诊断状态；
2. 按 BR-100 非空分组：逾期、待查看、今天、即将到来、需要补货；
3. 每张卡：类型图标、受隐私控制的标题、出现原因、业务时间/状态、一个最常用动作、更多动作；
4. 底部加载/时间窗口说明。

规则：

- 空状态不制造完成率，显示“先记一件最近想处理的小事”和加号；
- 同一对象聚合成一张卡，多个提醒用“还有 N 个提醒”等可展开信息；
- 刷新使用当前时钟和时区，跨午夜在前台时更新；
- 快捷动作先可访问性确认再乐观展示；失败回滚并显示现状；
- sensitive 未允许预览时卡片使用通用类型和状态，不暴露长度可推断正文。

### SCR-011：关注项操作面板

- 顶部显示通用对象摘要与“为什么在这里”；
- 动作完全来自 BR-030/REM-060 矩阵，顺序为主业务动作、稍后/知道了、打开详情；
- 不适用动作不显示也不置灰占位；
- destructive/冲突动作转对应确认/详情；
- 动作后关闭并让 SCR-010 从 Repository 刷新，不能只删本地卡片。

## 4. 生活簿、搜索和整理

### SCR-020：生活簿

- 导航栏：标题、搜索、筛选；主体顶部显示当前类型 segment/筛选摘要；
- 记录行：类型、隐私控制标题、说明摘要、适用业务日期/状态、分类/最多两个标签、置顶；
- 默认 active，置顶优先后按所选稳定排序；
- 滑动快捷只允许低风险且提供撤销，不放永久删除；
- 空空间显示创建入口，筛选为空显示清除筛选；
- P2 持续显示当前空间，不以颜色作为唯一空间区别。

### SCR-021：搜索

- 首项为自动聚焦搜索框、清除按钮和关闭；输入法提交不依赖；
- 输入后按类型分区或统一列表，命中字段标签和安全高亮；
- 未输入显示常用类型/筛选，不显示持久查询历史；
- 无结果提供检查筛选、清除和创建，不上传查询；
- 索引重建显示局部进度和可搜索范围；
- 离开/锁定清除原始查询和结果快照。

### SCR-022：筛选与排序

| 区域 | 内容 |
| --- | --- |
| 类型 | 五种多选，默认全部。 |
| 整理 | 分类单选/多选按 SRCH 规范、标签多选、置顶、需要关注。 |
| 状态 | active/archived 的适用选择；回收站不在此。 |
| 日期 | 预设与自定义本地日范围，说明按哪种业务日期。 |
| 排序 | 最近修改、最近创建、业务日期及稳定次序。 |

底部“重置 / 查看 N 条”；N 可高效计算时实时显示，否则用“查看结果”。取消不应用草稿筛选。

### SCR-023：清单模板库

- 系统模板与我的模板分区，卡片显示名称、用途、项目/分组数和相对建议；
- 主动作“从模板创建”走 FLOW-051，更多含 SCR-211 查看/复制，用户模板另有 FLOW-052 编辑/删除；新建模板进入 SCR-112；
- 系统模板只读，通过复制编辑；
- 空状态可新建模板或从清单另存；
- 删除模板确认只说模板，不暗示删除实例。

### SCR-024：归档内容

- 复用 SCR-020 行和搜索，但标题/说明固定“归档内容”；
- 行主动作“恢复活跃”，更多“删除到回收站 / 查看”；
- 恢复后的对象离开当前列表，提供撤销/查看；
- 空状态说明归档用于暂时收起，不等于删除。

## 5. 家中

### SCR-030：家中

从上到下：低库存摘要与 SCR-033 查看全部、SCR-031 全部物品入口、SCR-034 采购清单入口、SCR-032 最近库存流水。无物品时解释数量/位置用途并提供创建；有物品无阈值时不显示“库存正常率”。路由和返回状态遵循 FLOW-083。

### SCR-031：家庭物品列表

- 行显示名称、精确当前数量+单位、位置、低库存状态和主图缩略；
- 筛选位置、分类、标签、低库存，排序名称/最近变化/数量（同单位内）；
- 不跨不同单位做误导总量比较；
- 点行进入 SCR-240；快捷“库存操作”打开 SCR-241，不在滑动中一键扣减；从详情返回恢复筛选和滚动。

### SCR-032：库存流水列表

- 跨物品模式按 occurredAt 展示，单物品可切换 occurredAt 与 ledgerSequence；
- 行显示物品、kind、delta、before→after、发生时间和修正标记；
- 不提供编辑/删除；点行进入 SCR-240，“修正为实际数量”才进入 SCR-241；
- 过滤物品、kind、本地日期；没有结果区分无流水与筛选为空。

### SCR-033：低库存列表

- 每项显示“剩余 N 单位，最低库存 N”、进入时间、共享采购处理状态和当前收件人是否已知道；
- 主动作“加入采购清单”进入 SCR-034，次动作“知道了/查看”；查看进入 SCR-240；
- 当前收件人已知道的项仍可见但降低主动强调；家庭成员状态彼此独立，不显示全局 acknowledged；
- 阈值移除/数量恢复后自动离开，不提供虚假“完成”。

### SCR-034：采购清单入口

- 先列 active shopping 清单，最近使用优先，显示未完成项目数；
- 已有同物品项目时直接显示“更新现有项目”预览；
- 无清单时选择“新建采购清单”，进入 SCR-111 且带入建议项目；
- 提交前编辑购买数量，成功后打开 SCR-210；
- 取消不写 LowStockEpisode.handledAt、不确认 ReminderInstance，也不创建项目。

## 6. 全局创建和智能

### SCR-100：创建入口

- 上半区：多行纯文本输入、真实示例、字数状态、“帮我整理”；
- 下半区：重复事项、清单、备忘、重要日期、家庭物品五个始终可用入口；
- 智能不可用时输入仍可编辑，按钮旁说明状态与转手动；
- 超长不截断，提示缩短/转备忘；
- 关闭遵循 FLOW-002，不暗中保存输入。

### SCR-101：首次智能说明

必须同屏可读地展示：发送本次文字、固定日期/时区等上下文、不发送其他记录、模型供应商/地区详情入口、确认前不写入、手动替代。动作：“同意并继续 / 改用手动 / 取消”。不使用预勾选或倒计时同意。

### SCR-102：智能追问

- 显示原输入可折叠摘要、一个本地化问题、适用选项/输入控件；
- 主动作“继续整理”，次动作“改用手动”，关闭“取消”；
- 不显示聊天气泡历史或第二问题占位；
- 回答仍歧义时进入 SCR-105，不留在无限加载。

### SCR-103：草稿确认

- 顶部显示类型、可切手动的入口和“尚未保存”；
- 主体复用对应表单控件；inferred/default 在字段标签旁有文字/图标并可查看说明；
- 时间规则显示人类描述和未来 5 项；提醒显示完整绝对结果；物品显示期初流水预览；
- warnings 位于相关字段和顶部摘要，不展示 JSON/置信小数/推理；
- 底部“确认创建”，次动作“重新生成”，危险性最低的“取消”；
- 重新生成时旧草稿仍可编辑/确认，明确当前结果版本。

### SCR-104：创建成功

- 成功标题、类型和安全标题摘要；
- 展示适用“下一次时间 / N 个项目 / 当前库存 / 提醒状态”；
- 权限拒绝时准确说“记录已创建，系统通知未开启”；
- 动作“查看详情 / 再记一件 / 回到今天”；
- 页面不通过刷新/返回重复领域命令。

### SCR-105：智能创建故障

- 保留可编辑原文；
- 展示用户可理解状态：网络、暂不可用、额度、无法识别、多意图、不支持、安全拒绝、需升级；
- 动作按状态提供一次重试、选择手动类型、回输入或取消；
- 诊断 ID 可复制但不含内容；供应商原始错误不显示。

## 7. 五种表单和专项编辑器

### SCR-110：重复事项表单

字段顺序：标题 → 说明 → 开始日期 → 全天/时间及时间行为 → 重复规则摘要（SCR-116）→ 提醒（SCR-117）→ 分类/标签 → sensitive/AI access。编辑时显示“编辑系列”，仅本次从 SCR-201 发起，不混在根表单。

### SCR-111：清单实例表单

字段顺序：标题 → purpose → 分组/项目编辑器 → 可选截止 → 提醒 → 说明 → 分类/标签 → sensitive/AI access。项目行提供标题、展开说明、成对数量/单位、分组、拖动和删除；创建模式没有完成控件。

### SCR-112：清单模板表单

名称 → purpose → 分组/项目结构 → 相对截止建议 → 相对提醒建议 → 分类/标签。页面必须明确 `create`、`edit_user`、`copy_system`、`save_from_checklist` 四种模式，标题/主动作与来源匹配；保存进入对应 SCR-211，取消回 SCR-023、原 SCR-211 或 SCR-210 且不写入。不得出现绝对日期、isCompleted、完成时间、ReminderInstance 或记录附件。系统模板本体只读，copy_system 保存为新 ID 的 user 模板。

### SCR-113：备忘表单

标题 → 正文（主体大编辑区）→ 附件（SCR-119）→ 一个或多个绝对提醒 → 分类/标签 → sensitive/AI access。标题/正文不能同时空；编辑正文时不折叠成单行输入。

### SCR-114：重要日期表单

标题 → eventKind → calendarSystem（P0 仅公历且不显示不可用选择）→ once/yearly → 对应日期控件 → 可选 startYear → counterDisplay auto/hidden → 多提醒 → 说明/分类/标签/隐私。字段不可用时隐藏并向读屏说明变化，不留无意义 disabled 值。

### SCR-115：家庭物品表单

名称 → initialQuantity（创建必填，编辑不可作为当前数量直接改）→ unit → lowStockThreshold → 位置 → 说明 → 主图/附件 → 分类/标签 → 隐私。编辑已有非零流水时单位锁定并解释；当前数量改变转 SCR-241。

### SCR-116：重复规则编辑器

- frequency 选择；interval 数字+单位；
- weekly 显示星期和 weekStart 摘要，monthly 显示 1–31，多选去重，yearly 显示月日；
- endMode never/until/count 及对应输入；
- 粘性预览未来 5 项和时区/DST说明；
- 不合法/无候选显示字段错误；
- “完成”只把规则草稿返回 SCR-110，尚未保存记录。

### SCR-117：提醒编辑器

- 根据来源只显示合法 trigger；
- absolute 使用 ScheduleSpec；relative 选择提前量和适用本地时刻；at_schedule 无重复时间输入；
- 预览最终日期时间、时区和精确/近似状态；过去提醒必须修复/关闭；
- 重复催促默认关，开启后显示 interval/max/stopAfter；
- 保存返回宿主表单；删除计划需确认但不删除记录。

### SCR-118：分类与标签选择器

- 当前分类单选、标签多选和搜索；
- 快速新建先本地规范化查重，重复时选择既有；
- 显示标签计数但不泄露其他空间；
- “完成”返回选择草稿；管理/合并进入 SCR-420。

### SCR-119：图片与文件选择

- 显示允许类型、单个/总大小和剩余额度；
- 首次提供 SCR-901 后调用系统选择器；
- 选中后立即加密暂存、生成安全缩略和状态；
- 每项可取消/重试/移除，错误不清表单；
- sensitive 时缩略默认遮罩；P0 只有备忘和物品可进入。

## 8. 详情页

### 8.1 共通详情结构

导航栏标题/更多 → 类型状态摘要 → 主体内容 → 时间/提醒/历史 → 分类标签与元数据 → 适用主动作。删除/归档只在 SCR-300；系统 ID、revision 和模型来源默认不显示。

### SCR-200：重复事项详情

规则人类描述、下一次实例、未来列表、提醒、完成/跳过历史、编辑系列；有历史的大列表分页，分组历史不默认展开无限候选；变更范围进入 SCR-303。P1 增加“关联记录”区，添加进入 SCR-511，解除只删 RecordLink。

### SCR-201：周期实例详情

original/effective 时间、pending/completed/skipped/overdue 状态、完成/跳过/稍后/仅本次改期；变更范围进入 SCR-303。返回 SCR-200 时定位对应发生项；它不是独立 Record，不进入 SCR-511。

### SCR-210：清单实例详情

标题、目的、截止/提醒、进度文字、分组项目、添加/排序、批量完成、另存模板与复制清单；完成控件有 44pt 等价目标和读屏状态。大清单采用虚拟列表但保持读屏顺序和拖动替代按钮。另存模板进入 SCR-112，复制清单进入 SCR-111；P1 关联入口进入 SCR-511。

### SCR-211：清单模板详情

模板说明、分组项目只读预览、从模板创建、编辑、复制和删除；不显示完成率。system 模板只提供复制，user 模板可编辑/发布。删除使用页内影响确认，成功回 SCR-023；恢复模板从 SCR-434 进入本页。取消任何操作回本页且不修改模板；出口严格遵循 FLOW-051、FLOW-052、FLOW-322。

### SCR-220：备忘详情

标题、完整正文、附件、提醒状态、分类标签、置顶/敏感提示、编辑。正文可选择复制但敏感时先解锁；“知道了”仅在具体提醒/今天入口，不给根备忘完成状态。P1 关联区进入 SCR-511，解除不删除任一记录。

### SCR-230：重要日期详情

事件语义标题、下次公历日期、还有/已过天数、适用年龄/周年、历法/重复、提醒列表。当天不显示完成；hidden 时不留空年龄标签。P1 关联区进入 SCR-511。

### SCR-240：家庭物品详情

名称/主图、确认数量、可选“待同步预估”、阈值状态、位置、操作按钮、最近已过账流水、采购入口、说明/标签。pending/rejected intent 不伪装成流水；拒绝显示最新确认数量与修复入口。流水不可编辑/删除，详情只提供修正；P1 关联区进入 SCR-511。

### SCR-241：库存操作

kind、数量/目标数量、发生时间、备注、确认 before、输入与预估 after、阈值变化和提交。未绑定 after 负数时内联阻止；绑定离线可提交 pending 意图但必须显示“待同步”，服务端拒绝后保留原因和新 adjust 入口。adjust 明确“修正当前实际数量”并显示关联旧流水/baseLedgerSequence；提交不预先创建或改写 StockTransaction。

## 9. 通用操作和危险操作

### SCR-300：记录操作面板

按适用顺序：置顶/取消置顶、编辑、复制、归档/恢复、移动（P2）、删除到回收站。永久删除不在普通详情。显示当前空间，敏感/家庭高风险动作转专页。

### SCR-301：删除到回收站确认

显示对象类型/安全标题、取消未来提醒、30 天恢复期和附件/历史保留。绑定空间尚未同步时将日期标为估算，收到 serverPurgeAfter 后显示权威日期。低风险可用撤销条；系列、库存、附件显示加强说明。主动作“移到回收站”，取消为默认焦点。

### SCR-302：永久删除确认

显示记录或用户模板及聚合子对象/附件数、不可恢复、备份副本不受影响；模板明确“既有清单实例不删除”。要求重新认证和输入本地化确认词/等强度控件。主动作带对象名，不可用滑动返回提交。

### SCR-303：重复事项变更范围

显示原规则、新规则、切分日期、未来 5 项、剩余 count 和提醒变化；选“仅本次 / 本次及以后”，不提供改写已发生历史。冲突/空新段阻止确认。

### SCR-304：附件查看器

安全预览、文件类型/大小、页码/缩放、分享/重新选择/移除。missing/corrupt 不循环加载；后台立即遮罩并释放明文临时缓存。

## 10. 我的与设置

### SCR-400：我的

分组顺序：需要处理的状态 → 通知与提醒 → 分类标签 → 数据与存储 → 智能服务 → 隐私安全 → 帮助关于。P1 登录后账号/同步放最上方；未登录只展示开启价值。行可显示受控状态，不显示记录内容。

### SCR-410：通知与提醒设置

系统权限摘要、默认提醒、重复催促默认、应用静默时段、内容设置入口、调度水位与最近对账；异常进入 SCR-411。家庭空间 deletion_scheduled 时显示“提醒已暂停”，取消删除后只显示未来重建结果。

### SCR-411：权限状态与修复

逐权限真实状态、影响、系统设置入口、最后检查和“重新检查并安排”；Android 分开通知和精确提醒。已拒绝不提供无效“再次授权”按钮；回前台刷新。平台限制说明不能声称必达。

### SCR-420：分类与标签管理

分区列表显示名称、颜色、记录数、排序；创建/重命名/排序/合并/删除。合并预览目标和去重，删除说明不删记录；家庭空间持续显示上下文和权限。

### SCR-430：数据与存储

状态卡：最近验证备份、数据库/附件/缓存占用、回收站数。动作按安全顺序：创建备份、恢复、导出、回收站、清理可重建缓存、清除本机。恢复/清除不用相邻相同样式。

### SCR-431：创建加密备份

范围/估算 → 口令/确认 → 无法找回说明勾选 → 保存位置 → 阶段进度 → 验证结果。口令可显示/隐藏、粘贴允许；不显示强度伪评分，只显示具体规则。

### SCR-432：恢复加密备份

选择文件 → 口令 → 验证进度 → 范围/版本/空间预览 → 覆盖强确认 → 恢复/自检 → 结果。错误口令、损坏、不兼容、空间不足分别说明；任何验证错误不改变当前数据。

### SCR-433：数据导出

格式、范围、附件和 sensitive 选择 → 未加密风险 → 认证 → 生成进度 → 系统分享。完成页说明 App 外副本不受控制并提供清理 App 暂存状态。

### SCR-434：回收站

按剩余天数/删除时间列出记录和用户模板，行提供恢复和永久删除；绑定删除待服务端确认时显示“删除日期待同步确认”，不用本地估算承诺日期。顶部搜索/类型筛选，更多“清空回收站”。模板恢复打开 SCR-211；过期清理中的对象显示状态，不允许同时恢复。

### SCR-435：清除本机数据

显示本机范围、最近备份、外部文件/P1 云端不受影响，提供先备份。强认证+确认词；进行中不可退出到主框架；结果必须经过空数据自检。

### SCR-440：智能服务

当前可用/接近额度/不可用、数据说明版本、实际地区供应商详情、首次说明重看、手动替代；P1 增加多轮/语音和 SCR-522。不得展示供应商 Key 或完整请求。

### SCR-450：隐私与安全

应用锁、通知内容、敏感默认、AI 默认、可选遥测、隐私说明；分别进入 SCR-451、SCR-452。修改更严格设置立即生效并排队重排，放宽不自动暴露旧通知。

### SCR-451：应用锁设置

认证能力、开启/关闭、自动锁定时机和失败恢复；系统认证取消不改设置，两种认证都不可用时只提供恢复/安全清除，不能绕过。

### SCR-452：通知内容设置

完整内容、只显示标题、完全隐藏三种实例预览，明确 sensitive 始终完全隐藏；保存后重排既有适用通知，失败进入 SCR-411。

### SCR-460：帮助与关于

版本/构建、提醒排查、备份恢复说明、数据位置、智能数据说明、反馈/支持、开源许可、隐私/条款/第三方。复制诊断信息先预览且无内容。从 SCR-001 启动阻断进入时使用无数据库模式，只加载随 App 打包的版本、恢复说明、法律/支持入口和传入诊断 ID；返回 SCR-001，不构造 SCR-400 主导航。

## 11. 系统界面

### SCR-900：系统通知

使用 REM-060 类别动作和 REM-070 内容模式；payload 只含不透明 ID/版本。动作标题短、来源适配；敏感只有通用内容和打开。通知消失不等于业务完成。

### SCR-901：权限前置说明

底部页/页面内说明包含用途、具体收益、拒绝影响、“继续 / 暂不”。只在紧邻功能时出现，不用恐吓、假系统弹窗或预勾选。

### SCR-902：系统文件选择/分享

调用前记录加密流程状态；取消返回原页且不报错；App 后台遮罩；返回的 URI/权限在复制完成后最小化释放。

### SCR-903：系统生物识别

只由明确用户动作或锁屏恢复触发；系统回调映射成功、取消、失败、锁定、不可用，不用自制生物特征界面。

## 14. 页面覆盖检查

实现新页面或状态时必须验证：

- 其 SCR ID 存在于信息架构且阶段一致；
- 入口和离开路径存在于 FLOW-*；
- 每个可编辑值能映射领域字段或明确 UI 临时状态；
- 每个业务动作映射领域命令，不直接改表；
- 有 loading/empty/partial/offline/permission/error/locked/conflict 的适用设计；
- 敏感、空间和账号上下文持续可辨；
- 内容键、可访问名称、焦点顺序和动态字体由对应规范覆盖；
- 自动化测试可以用稳定语义标识找到控件，不依赖屏幕坐标或最终中文文案。
